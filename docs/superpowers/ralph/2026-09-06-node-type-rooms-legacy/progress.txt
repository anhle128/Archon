## Codebase Patterns
### Root lint heap
- **Where**: `package.json` `lint` / `validate`
- **Pattern**: Default Node heap can OOM on `bun run lint --max-warnings 0` (~4 GB). Retry with `NODE_OPTIONS='--max-old-space-size=8192' bun run lint --max-warnings 0` (and the same prefix on `bun run validate`).
- **Gotcha**: Do not drop `--max-warnings 0`. Lint production files only; web `*.test.ts` is eslint-ignored.

### LegacyNodeLogs wiring
- **Where**: `packages/web/src/components/workflows/LegacyNodeLogs.tsx`, `packages/web/src/components/workflows/WorkflowExecution.tsx`
- **Pattern**: Keep list/selection/reset/header/footer. Replace `NodeTranscriptPane` with one `LegacyNodeRoom` and pass `definitionNodes`, `definitionPending`, `events`, `runStatus`, `approval`, `onApprove`, `onReject`. Store `approval` on `WorkflowRunQueryData` from `data.run.metadata.approval ?? null`. Gate handlers `await` API then invalidate `['workflowRun', runId]` with no catch so `GateRoom` sees the rejection. Pass new props only on the Logs branch.
- **Example**: `runStatus={queryData?.workflowState.status ?? workflow.status}`
- **Gotcha**: Logs tests stay on happy-dom + `QueryClientProvider` + `notifyManager`. Agent fixtures need a `command` definition. Loop-group list rows come from `loop_iteration_*` on the group id; room chrome still reads qualified body events (`group.body`). Lint production files only.

### LegacyNodeRoom dispatcher
- **Where**: `packages/web/src/components/workflows/LegacyNodeRoom.tsx`
- **Pattern**: Null `row` returns `RoomPlaceholder` "Select a node" with no region. Selected rows render header (label, `TYPE_LABELS[nodeType]` or `Loading`, status token) outside the body. `waitingForDefinition` is `definitionPending && definitionNode === null && kind === 'agent' && nodeType === 'unknown'`. Exhaustive `switch (resolution.kind)` with local `assertNever`. Only `'agent'` mounts `NodeTranscriptPane`. Do not wrap `body` in a second `RoomRegion`.
- **Example**: `waitingForDefinition ? 'Loading' : TYPE_LABELS[resolution.nodeType]`
- **Gotcha**: Happy-dom agent cases need `QueryClientProvider` + `notifyManager` like `NodeTranscriptPane.test.tsx`. Non-agent rooms stay `renderToStaticMarkup` because `useQuery` never mounts. Lint production files only.

### LoopGroupRoom authored topology + iteration accordions
- **Where**: `packages/web/src/components/workflows/LoopGroupRoom.tsx`
- **Pattern**: Always wrap in one `RoomRegion` and render heading `Loop group`. `Body nodes` lists authored `id` plus `Start` or `After ${dependsOn.join(', ')}`. Empty `iterations` still shows topology plus `RoomPlaceholder` "Node hasn't produced output". Non-empty maps one `<details open={iteration === selectedIteration}>` per iteration; summary is U+00D7 + iteration + status; body lists `qualifiedId` + derived status.
- **Example**: `{'×' + String(iteration.iteration) + ' ' + iteration.status}`
- **Gotcha**: Do not add SVG, dagre, React Flow, or clickable nested graph nodes. Static markup tests via `renderToStaticMarkup`.

### RouteControllerRoom inspection-only card
- **Where**: `packages/web/src/components/workflows/RouteControllerRoom.tsx`
- **Pattern**: Always wrap in one `RoomRegion` and render heading `Routing decision`. Null `decision` → `RoomPlaceholder` inside the labelled region. Present decisions use a `<dl>` whose rows come from `FIELDS` and are omitted when `decision[key] === null`. 9rem label column; `font-mono` on every `dd`.
- **Example**: `grid-cols-[9rem_1fr]` + skip `decision[key] === null`
- **Gotcha**: Do not invent route mutation controls or an agent timeline. Static markup tests via `renderToStaticMarkup`. `×` in later stories is U+00D7.

### ChildWorkflowRoom inspection-only card
- **Where**: `packages/web/src/components/workflows/ChildWorkflowRoom.tsx`
- **Pattern**: Always wrap in one `RoomRegion` and render heading `Child run`. Show paused banner (`child.message ?? 'Sub-run is paused awaiting review'`), fan-out copy, `encodeURIComponent` child-run `<a>`, and `font-mono bg-surface-inset` output only when those fields are set. `RoomPlaceholder` only when `!hasContent`.
- **Example**: `encodeURIComponent(child.childRunId)` in the Open child run href
- **Gotcha**: Fan-out with `childRunId: null` must not invent `Open child run`. Never call the transcript loader. Static markup tests via `renderToStaticMarkup`.

### GateRoom local action runner
- **Where**: `packages/web/src/components/workflows/GateRoom.tsx`
- **Pattern**: Wrap in one `RoomRegion`. Render `chrome.message` always; document/pre and Open Plannotator (`target="_blank"` `rel="noopener noreferrer"`) only when non-null; Approve + `ConfirmRunActionDialog` Reject only when `canDecide`; inactive banner `Gate is not the active pause` with `bg-warning/5 border-warning/20`; decision text `Approved`/`Rejected`. Own `actionPending`/`actionError`; `void runAction(...)` from clicks; failures in `<p role="alert" className="text-sm text-error">`.
- **Example**: `void runAction(onApprove)` / `void runAction(() => onReject(reason))`
- **Gotcha**: Happy-dom GateRoom tests must `act` + `flush` after `root.render`. Do not `expect(markup).not.toContain('Approve')` when the banner says `Approved`. Reuse dashboard `ConfirmRunActionDialog`; do not re-parse `reviewUrl`. Lint production files only.

### Shared RoomRegion / RoomPlaceholder
- **Where**: `packages/web/src/components/workflows/NodeRoom.tsx`, `packages/web/src/components/workflows/StdoutRoom.tsx`
- **Pattern**: Unselected NodeRoom returns `RoomPlaceholder` with no region. Every selected body (loading/error/empty/loaded, and every dedicated room) wraps in exactly one `RoomRegion` (`role="region"` `aria-label={`${nodeId} room`}`). StdoutRoom renders `<pre>` whenever `text` is a string (including `''`); `RoomPlaceholder` "Node hasn't produced output" only when `text === null`. Truncation copy is `Output truncated from N bytes` or `Output truncated`. `Exit status: 0` only when `exitCode === 0`.
- **Example**: `<RoomRegion nodeId={nodeId}>…</RoomRegion>`
- **Gotcha**: Do not wrap unselected state. Do not import console rooms. Tests are eslint-ignored — lint production files only.


### Attempt-scoped selectors
- **Where**: `packages/web/src/components/workflows/select-room-data.ts`
- **Pattern**: Ordinary rows slice `events` from `row.id` then filter `step_name`. Last `node_completed`/`node_failed` in that slice wins — a later failure suppresses an earlier completion. Route rows match `data.execution_seq` exactly. Loop-group rows scan the original array, ignore `eventsForRow`, and last-lifecycle-wins per `(iteration, qualifiedId)`.
- **Example**: `selectNodeStdout(events, row)` / `selectLoopGroupChrome({ definitionNode, events, row })`
- **Gotcha**: Array order is the attempt clock, not `created_at`. `isRecord` guards `event.data`. Do not parse error prose for exit codes.

### Pure resolveRoomKind classifier
- **Where**: `packages/web/src/components/workflows/resolve-room-kind.ts`
- **Pattern**: Definition lookup first via recursive `loop_group` qualified IDs (`prefix + '.' + node.id`). Then matching `readApprovalContext` (`child_workflow` → workflow; `approval`/`plannotator_gate`/omitted → gate). Then events: any `node_routed`, latest bash/script `node_started|completed|failed`, latest workflow `node_completed|failed`, latest `approval_requested`. Else agent/`unknown`.
- **Example**: `resolveRoomKind('group.nested.check', nodes, events, approval)`
- **Gotcha**: Scan from the array end for "latest". Do not treat `interactive_loop`/`writeback` as gate/workflow. `ROOM_BY_BODY` is a frozen map, not mutable module state.

### Shared web ApprovalContext boundary
- **Where**: `packages/web/src/lib/approval-context.ts`
- **Pattern**: Parse run metadata with `readApprovalContext(unknown)` (required `nodeId` + `message` strings; optional typed enums). `getPlannotatorReviewUrl({ status, approval })` returns a normalized HTTP(S) `url.href` only for paused `plannotator_gate` rows.
- **Example**: `getPlannotatorReviewUrl({ status: run.status, approval: run.metadata.approval })`
- **Gotcha**: Callers and dashboard fixtures must include `nodeId` and `message`. Incomplete `{ type, reviewUrl }` objects fail the parser even when the old private helper accepted them.

### Web tests are ESLint-ignored
- **Where**: `packages/web` eslint ignore for `*.test.ts`
- **Pattern**: Lint production files only (`bun x eslint <prod files> --max-warnings 0`). Passing ignored test paths to eslint with `--max-warnings 0` fails as a warning.
