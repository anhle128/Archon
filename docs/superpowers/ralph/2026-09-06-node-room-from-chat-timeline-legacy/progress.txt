## Codebase Patterns

### Web component tests need NODE_ENV=development
- **Where**: `packages/web/package.json` `test` script
- **Pattern**: `bun test src/components/` shares one process. Static `react` / `react-dom/server` imports load production React first, so later files that set `process.env.NODE_ENV = 'development'` still see `react.act === undefined`. Run that bun invocation with `NODE_ENV=development`.
- **Example**: `NODE_ENV=development bun test src/components/`

### Multi-hunk edits on large TSX files
- **Where**: `packages/web/src/components/workflows/WorkflowExecution.tsx`
- **Pattern**: Line-anchored/search-replace on this ~900-line file truncated it to ~300 lines even when applied sequentially. Apply all hunks in one in-process rewrite (read → replace → write) and verify `wc -l` afterwards.
- **Example**: Python `text.replace(old, new, 1)` for each unique hunk, then `path.write_text(text)`.

### Chat door queries and exact timeline selection
- **Where**: `packages/web/src/components/workflows/LegacyGraphLogsPane.tsx`
- **Pattern**: Parent queries enable only when `activeView === 'chat' && parentPlatformId !== null`. Message polling uses `runChatMessagesRefetchInterval(runStatus)` (3000 for pending/running/paused, false for terminal). `selectedTimelineEntryId` is independent of `selectedLogRowId`; Graph/Logs clicks and run changes clear it, tab switches do not. Synthetic `resolveGraphRoomRow` fallbacks keep `selectedLogRowId` null so the row-removal effect does not wipe Chat selection. `find(... )?.nodeId` does not narrow `ChatTimelineEntry` — loop and assign `nodeId` inside `kind === 'node_status'`.
- **Example**: `setSelectedLogRowId(rowExists ? row.id : null); setSelectedTimelineEntryId(entry.id); onSelectNode(row.nodeId);`

### React 19 + happy-dom controlled textarea
- **Where**: `packages/web/src/components/workflows/LegacyGraphLogsPane.test.tsx`
- **Pattern**: Native `HTMLTextAreaElement.prototype.value` setter + `InputEvent` does not update React 19 controlled state under happy-dom. After the native setter, invoke the fiber `onChange` via `__reactProps$`. Do not use `instanceof win.HTMLTextAreaElement` against `Element` from `querySelector` — the intersection is `never` (`ELEMENT_NODE` conflict); check `tagName` and cast. Wait until the textarea has no `disabled` attribute before submit tests — conversation query starts in `'Loading conversation…'`.
- **Example**: `setNativeTextareaValue(textarea, value)` then `__reactProps$*.onChange({ target: { value } })`


### Controlled run composer (no API/HITL)
- **Where**: `packages/web/src/components/workflows/RunChatComposer.tsx`, `packages/web/src/lib/api.ts`
- **Pattern**: Composer is fully controlled and has zero API/HITL imports. `disabled = sending || disabledReason !== null`; `disabledReason` is placeholder + form `title` only (never a second text node). `getConversation` calls `fetchJSON` with no options so `fetch(url)` is a single-arg GET — tests use `toHaveBeenCalledWith(ENCODED_URL)`.
- **Example**: `{props.sending ? 'Sending…' : 'Send'}` and `disabled={disabled || props.value.trim().length === 0}`

### Lucide icon lookup vs naming-convention
- **Where**: `packages/web/src/components/workflows/ChatTimeline.tsx`
- **Pattern**: `@typescript-eslint/naming-convention` rejects PascalCase locals (`Icon`). Render a mapped lucide component with `createElement(TYPE_ICONS[nodeType], props)` instead of `<Icon />`.
- **Example**: `createElement(TYPE_ICONS[entry.nodeType], { 'aria-hidden': true, className: 'h-3.5 w-3.5 shrink-0 text-text-tertiary' })`

### Timeline room resolution
- **Where**: `packages/web/src/components/workflows/resolve-timeline-room-row.ts`
- **Pattern**: Reverse-scan `LogRow[]` for the last exact `nodeId` + `LogRowSelection` match, then `resolveGraphRoomRow`. Throw `'Timeline node selection did not resolve a room row'` when fallback is null (public type is `LogRow | null`). `row !== undefined && row.nodeId` trips `@typescript-eslint/prefer-optional-chain` — use `if (row === undefined) continue` then compare.
- **Example**: `selectionsEqual` returns true for `{ kind: 'node' }` once kinds match; loop/route compare `iteration` / `executionSeq`.

### Chat timeline merger
- **Where**: `packages/web/src/components/workflows/build-chat-timeline.ts`
- **Pattern**: Pure indexed merge of user messages then node-status events; sort by `Date.parse(ensureUtc(createdAt))` (non-finite → 0), then `user` before `node_status`, then encounter index. Call `resolveNodeType` only after an event passes node-id and whitelist checks.
- **Example**: `mapNodeEvent` returns null for every non-whitelisted `event_type`; loop/route labels reuse `build-log-rows.ts` (` ×N` / ` #N`).

### WorkflowEvent union fixtures
- **Where**: `packages/web/src/components/workflows/build-log-rows.test.ts`, `build-chat-timeline.test.ts`
- **Pattern**: `WorkflowEventResponse` is a union (`node_routed` branch vs generic). Typed fixture builders with `Partial<WorkflowEventResponse>` keep OpenAPI fields explicit; incomplete `node_routed` rows can still use `data: {}` on the generic branch.
- **Example**: `const event = (overrides: Partial<WorkflowEventResponse> = {}): WorkflowEventResponse => ({ id, workflow_run_id, event_type: 'node_started', step_index: null, step_name: 'review', data: {}, created_at, ...overrides })`

### Awaiting is a first-class node state
- **Where**: `packages/web/src/lib/run-graph/types.ts`, `packages/web/src/lib/types.ts`, `packages/web/src/components/workflows/build-run-graph-input.ts`
- **Pattern**: `WorkflowStepStatus` and `NodeState` both include `'awaiting'`. Switches over those unions must handle `awaiting` or `tsc` fails with TS2366.
- **Example**: `toNodeState` includes `case 'awaiting': return status`.
