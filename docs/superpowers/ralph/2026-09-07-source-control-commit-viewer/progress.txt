## Codebase Patterns

### Set viewerScopeRef before starting a viewer request
- **Where**: `packages/web/src/components/workflows/source-control/source-control-tab.tsx` `onOpenScopedFile`
- **Pattern**: Assign `viewerScopeRef.current = scope` and `setViewerScope(scope)` synchronously before `beginRequest()`. Capture `fetchSpy` into a const before `waitFor` closures so tsc does not re-widen `let fetchSpy`.
- **Example**: `viewerScopeRef.current = scope; setViewerScope(scope);`

### Route commit changes separately from Now in mockGitRoutes
- **Where**: `packages/web/src/component-integration/source-control-tab.test.tsx` `mockGitRoutes`
- **Pattern**: Parse `ref` from `/git/changes` with `new URL(url, 'http://archon.local')`. A present `ref` must not increment the Now `changesCall` counter. Story 2.1 Enter-to-expand tests need `onCommitChanges`.
- **Example**: `if (ref !== null) { commitChangesCall += 1; ... }`


### Isolate nested History keyboard at the listbox boundary
- **Where**: `packages/web/src/components/workflows/source-control/commit-history-graph.tsx` `onKeyDown`
- **Pattern**: Return when `event.currentTarget !== event.target` so nested `ChangedFilesList` Arrow/Enter/Space cannot move or collapse the outer History row. Enter/Space on the History listbox itself calls `onToggleCommit`.
- **Example**: `if (event.currentTarget !== event.target) return;`

### SourceControlPanel expand props are required
- **Where**: `source-control-panel.tsx`, `source-control-tab.tsx`, `source-control-tab.test.tsx`
- **Pattern**: `expandedCommit`, `commitSnapshot`, `commitLoadState`, `onToggleCommit`, and `onOpenCommitFile` are required. Direct `createElement(SourceControlPanel, …)` tests must pass idle/null stubs. Derive files with `commitSnapshot != null` because `undefined !== null` is true.
- **Example**: `props.commitSnapshot != null && props.commitSnapshot.emptyReason === undefined`

### Split Changes vs commit selected paths
- **Where**: `packages/web/src/components/workflows/source-control/source-control-panel.tsx`
- **Pattern**: `selectedNowPath` for Changes, `selectedCommitPath` for History files, so the same path cannot appear selected in both lists.
- **Example**: `selectedPath={props.selectedNowPath}` vs `selectedPath={props.selectedCommitPath}`

### Regenerate OpenAPI types from a worktree-specific port
- **Where**: `packages/web/package.json` `generate:types`, `packages/web/src/lib/api.generated.d.ts`
- **Pattern**: `generate:types` is hardcoded to `http://localhost:3090/api/openapi.json`. When 3090 is already bound, start this worktree's server on a free port and run `bun x openapi-typescript http://localhost:<port>/api/openapi.json -o src/lib/api.generated.d.ts`. Never hand-edit the generated file. Confirm `ref` on `/git/changes` and `/git/diff`.
- **Example**: `PORT=39079 bun run dev:server` then `bun x openapi-typescript http://localhost:39079/api/openapi.json -o src/lib/api.generated.d.ts`

### Locked GitFileSource union needs a redundant-constituents disable
- **Where**: `packages/web/src/lib/api.ts` `GitFileSource`
- **Pattern**: `'worktree' | 'head' | string` is the locked contract; it trips `@typescript-eslint/no-redundant-type-constituents` the same way `'live' | string` does. Keep the union and disable the next line.
- **Example**: `// eslint-disable-next-line @typescript-eslint/no-redundant-type-constituents -- locked GitFileSource contract`

### Validate HTTP ref before checkout lookup
- **Where**: `packages/server/src/routes/git/changes-handler.ts`, `diff-handler.ts`, `file-handler.ts`
- **Pattern**: `c.req.query('ref') !== undefined` plus `isValidGitObjectId` rejects empty `ref=` and `HEAD` before `loadRunCheckout`. Now listing must call `changedFiles(path)` with one argument. Map `GitCommitRefError` / `GitFileError` `invalid_ref` to HTTP 400 `{ error: 'Invalid commit ref' }` and log `{ runId, errorType: 'invalid_ref' }` without the OID.
- **Example**: `if (ref !== undefined && !isValidGitObjectId(ref)) return apiError(c, 400, 'Invalid commit ref');`

### Isolate commit fileDiff fixtures and spawn spies
- **Where**: `packages/git/src/file-read.test.ts` `commit fileDiff`
- **Pattern**: Bun runs tests concurrently. Give each commit fileDiff case its own repo under the describe temp root. When spying `child_process.spawn`, assert the `diff-tree` argv only — flattened calls can include concurrent Now `git diff HEAD` spawns.
- **Example**: `const diffTree = spawnedArgv.find(args => args.includes('diff-tree')); expect(diffTree).not.toContain('HEAD');`

### Keep explicit root vs parent fileDiff argv
- **Where**: `packages/git/src/file-read.ts` `fileDiff`
- **Pattern**: Two literal `diff-tree` argv arrays like `changedFiles` (root inserts `--root` after `--no-commit-id` and omits parent; non-root is `parentOid commitOid`). Commit branch uses `acceptExitCodes: [0]`; Now keeps `git diff HEAD` with `[0, 1]`. `fileAt` only calls `resolveCommitParents` when `treeIsh` matches `FULL_GIT_OBJECT_ID_RE` so `HEAD` stays unchanged.
- **Example**: `if (source.kind === 'tree' && FULL_GIT_OBJECT_ID_RE.test(source.treeIsh)) await resolveCommitParents(workingPath, source.treeIsh);`

### Git-oid helpers stay package-internal
- **Where**: `packages/git/src/git-oid.ts`, `packages/git/src/index.ts`
- **Pattern**: `parseGitObjectId`, `resolveCommitParents`, `FULL_GIT_OBJECT_ID_RE`, and `GitCommitRefError` are imported by sibling modules. Export `parseNameStatusZ` and `ChangedFilesRequest` from the package root; do not re-export git-oid symbols.
- **Example**: `import { parseGitObjectId, resolveCommitParents } from './git-oid';`

### Keep explicit root vs parent diff-tree argv
- **Where**: `packages/git/src/changed-files.ts` `changedFiles`
- **Pattern**: Two literal argv arrays (root uses `--root` and omits parent; non-root is `parentOid commitOid`). Do not extract a one-use builder (Rule of Three). Now porcelain stays on the no-`commit` branch and must not call `parseGitObjectId` or `resolveCommitParents`.
- **Example**: `parents[0] === undefined ? [..., '--root', ..., commit] : [..., parents[0], commit]`

### Isolate commit-listing fixtures per test
- **Where**: `packages/git/src/changed-files.test.ts` `commit changedFiles`
- **Pattern**: Bun runs tests concurrently. Give merge-commit coverage its own repo under the describe temp root instead of mutating the sibling test's checkout.
