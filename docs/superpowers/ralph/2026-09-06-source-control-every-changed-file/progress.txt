## Codebase Patterns
### Load more dual Cancel and frozen fingerprints
- **Where**: `packages/web/src/components/workflows/source-control/source-control-tab.tsx`
- **Pattern**: `abortCurrent` clears `loadingMore`. Cancel during a page aborts only that request; Cancel during initial loading still closes. Append text/hunks in place; never `dispatch` from Load more. HTTP 409 keeps painted content and calls the existing `onReload` comparison. Truncated diffs freeze `reloadFingerprint` as the first cursor; complete diffs freeze first-response JSON.
- **Example**: `reloadFingerprint: response.truncated && response.cursor !== '' ? response.cursor : JSON.stringify(response)`

### Happy-dom virtualizer height floor
- **Where**: `packages/web/src/components/workflows/source-control/virtualized-diff.tsx` (`observePaneRect`)
- **Pattern**: happy-dom `getBoundingClientRect()` is 0×0, so the default ResizeObserver would replace `initialRect: { width: 0, height: 280 }` with an empty viewport and mount every hunk. Floor measured height to 280. Import `Diff` from `react-diff-view/esm/index.js` so `Bun.build` metafile lists `node_modules/lodash/` (the packaged `es/index.js` inlines lodash).
- **Example**: `height: Math.max(Math.round(rect.height), 280)`

### FileViewerState locked kinds
- **Where**: `packages/web/src/components/workflows/source-control/file-viewer.tsx`
- **Pattern**: `binary` is gone. Text carries `truncated`+`cursor`; diff carries `reloadFingerprint`; image/hex/download replace the old binary state. Load more shows only for truncated text/diff with a non-empty cursor and `onLoadMore`; Cancel shows for initial loading or `loadingMore`.
- **Example**: `{ kind: 'diff', file, response, reloadFingerprint: response.truncated && response.cursor ? response.cursor : JSON.stringify(response) }`

### Web GitFileClientResult presentations
- **Where**: `packages/web/src/lib/api.ts` (`gitFileUrl`, `getWorkflowRunGitFile`)
- **Pattern**: `gitFileUrl` emits `cursor`/`download=1` only when set, using `URLSearchParams` after per-segment path encoding. Presented responses (`X-Archon-Git-Presentation`) require ETag, non-negative `Byte-Length`, exact `true`/`false` truncated, and a non-empty cursor exactly when text is truncated. `response.text()` is text-only; `arrayBuffer()` is image/hex; download cancels `response.body` without reading. Missing presentation headers keep the Story 1.2 fallback (JSON CAP-6, text as an untruncated final page, octet-stream as download-only).
- **Example**: `gitFileUrl(runId, path, 'worktree', { cursor: 'ab+c', download: true })`

### HTTP git cursor and presentation boundary
- **Where**: `packages/server/src/routes/git/diff-handler.ts`, `packages/server/src/routes/git/file-handler.ts`
- **Pattern**: `invalid_cursor` → HTTP 400 `{ error: 'Invalid file cursor' }`; `stale_cursor` → HTTP 409 `{ error: 'File changed' }`. Logs only `{ runId, errorType }`. Presentation headers and ETag are set only after CAP-6/error branches. `download=1` uses `intent: 'download'` plus attachment + `Content-Length`; other requests use `intent: 'view'` with optional cursor. Stream delivery returns `result.stream` as the Response body.
- **Example**: `fileAt(workingPath, path, source, { intent: 'download', signal: c.req.raw.signal })`

### Incremental unified diff paging
- **Where**: `packages/git/src/diff-page.ts`, `packages/git/src/file-read.ts`
- **Pattern**: Stream `git diff` stdout through one `TextDecoder` plus a pending incomplete line. `HunkPageAccumulator` skips `startIndex` hunks, keeps the first selected hunk even when oversized, and returns `page_full` before a later hunk that would exceed 256 KiB serialized JSON or 2,000 changes. `fileDiff` cancels the git-stream reader on `page_full` so the child is killed. Version hash is SHA-256 of both worktree and HEAD identity hashes; hunk cursors use axis `h`.
- **Example**: `visitUnifiedDiffChunks(chunks, hunk => pager.push(hunk))` then `encodeViewerCursor('h', page.nextIndex, version)`

### git-stream acceptExitCodes
- **Where**: `packages/git/src/git-stream.ts`
- **Pattern**: `streamGitStdout` defaults to treating only exit 0 as success. `git diff` exits 1 when hunks exist, so callers pass `acceptExitCodes: [0, 1]`. Cancel still sets `intentionalStop` and kills the child.
- **Example**: `streamGitStdout({ workingPath, args: ['diff', ...], acceptExitCodes: [0, 1] })`

### Modified non-text diffs fall back
- **Where**: `packages/git/src/file-read.ts` (`fileDiff`)
- **Pattern**: Inspect worktree and HEAD with bounded probes. If either side is image, hex, or download, return `hunks: []`, `fileFallback: true`, and `binary` from whether a probe contained NUL. SVG is image + `binary: false`.
- **Example**: `fileDiff(workingPath, 'image.svg')` → `{ fileFallback: true, binary: false, hunks: [] }`


### Git package error classes
- **Where**: `packages/git/src/git-path.ts`, `packages/git/src/file-read.ts`, `packages/git/src/viewer-limits.ts`
- **Pattern**: Domain errors extend `Error`, set `this.name`, and expose a readonly `code` union. Callers distinguish branches via `code`, not message text.
- **Example**: `class ViewerCursorError extends Error { readonly code: 'invalid' | 'stale' }`

### Locked viewer cutoffs
- **Where**: `packages/git/src/viewer-limits.ts`
- **Pattern**: First-paint, stream, download-only, hex peek, binary probe, and diff context are exported numeric constants. Downstream stories must import these rather than restating literals.
- **Example**: `VIEWER_FIRST_PAINT_BYTES = 256 * 1024`, `VIEWER_DOWNLOAD_ONLY_BYTES = 50 * 1024 * 1024`

### Opaque viewer cursors
- **Where**: `packages/git/src/viewer-limits.ts` (`encodeViewerCursor` / `decodeViewerCursor`)
- **Pattern**: Unpadded base64url JSON with exactly one axis key (`o` or `h`) plus `v` (64 lowercase hex). Canonicalize by decode-then-re-encode. Empty cursor → 0. Wrong axis / extra fields / padding → `invalid`. Version mismatch → `stale`.
- **Example**: `encodeViewerCursor('o', 4096, 'a'.repeat(64))`

### InspectedFile + internal git-stream
- **Where**: `packages/git/src/file-read.ts`, `packages/git/src/git-stream.ts`
- **Pattern**: `fileAt` inspects size first, then reads only the window the presentation needs. Tree blobs use `ls-tree` + `cat-file -s` then spawned `cat-file blob` via internal `streamGitStdout` / `readGitStdoutWindow`. `git-stream.ts` is package-internal — never re-export from `index.ts`.
- **Example**: `fileAt(path, rel, source, { intent: 'view', cursor })` vs `{ intent: 'download' }` returning `delivery: 'stream'`

### fileAt overloads stay full-read compatible
- **Where**: `packages/git/src/file-read.ts`
- **Pattern**: Default/omitted request is `intent: 'full'` and returns `FileAtBytesResult` (all bytes). HTTP handlers that call `fileAt(workingPath, path, source)` keep compiling against `.bytes`. View/download are extra overloads.
- **Example**: `fileAt(workingPath, path, { kind: 'worktree' })` → bytes
