## Codebase Patterns

### Shared Graph/Logs room pane
- **Where**: `packages/web/src/components/workflows/LegacyGraphLogsPane.tsx`, `resolve-graph-room-row.ts`, `WorkflowExecution.tsx`
- **Pattern**: Keep `selectedLogRowId` for iteration-specific Logs clicks. Displayed row is that explicit row only while it exists and belongs to `selectedNodeId`; otherwise `resolveGraphRoomRow`. Graph clicks always clear the explicit row first. One `ResizablePanelGroup` (60/40) hosts either `renderGraph` or `NodeRunList` on the left and a single `LegacyNodeRoom` on the right. `resolveWorkflowExecutionBody` returns `graph-logs-pane` for DAG Graph, Logs, and Chat-without-parent.
- **Example**: `activeView={activeView === 'graph' ? 'graph' : 'logs'}`

### React Flow view model from pure layout
- **Where**: `packages/web/src/components/workflows/build-workflow-dag-view-model.ts`, `RunGraphRouteEdge.tsx`, `WorkflowDagViewer.tsx`
- **Pattern**: Call `layoutRunGraph` once. Copy `resolveExecutionNodeDisplay` plus live metadata onto `ExecutionFlowNode`. Each route becomes `type: 'runGraphRoute'` with `data.route`, `MarkerType.ArrowClosed`, and `animated` only when the target status is `running`. Register `edgeTypes` at module scope. Stroke from taken/kind/outcome; dash when `backEdge || kind === 'conditional'`. Do not import dagre into the viewer.
- **Example**: `const edgeTypes: EdgeTypes = { runGraphRoute: RunGraphRouteEdge };`

### Workflow-to-layout adapter
- **Where**: `packages/web/src/components/workflows/build-run-graph-input.ts`
- **Pattern**: Keep DagNode/`ROUTE_LOOP_OUTCOMES` imports out of `run-graph/`. Map live `WorkflowStepStatus` with an exhaustive switch so `awaiting` cannot leak. Emit route edges via `[...ROUTE_LOOP_OUTCOMES].reverse()` (exhausted, negative, positive). First free id is `${source}->${target}`; collisions use `${source}->${target}:${outcome}`.
- **Example**: `return layout(buildRunGraphInput(dagNodes, liveStatus));`

### Cubic SVG path formatter
- **Where**: `packages/web/src/lib/run-graph/routes.ts`
- **Pattern**: Every route is one cubic `M x y C x y x y x y` string. Classify in order: omit if either endpoint lacks a position, self-edge (left→top gutter), `backEdgeIds` (left→left flank), else forward. Short forward uses top port when layer span ≤ 1 or |center dx| ≤ SIDE_PORT_THRESHOLD. Copy optional `label`/`outcome` only when defined so missing keys stay absent.
- **Example**: `` `M ${start.x} ${start.y} C ${control1.x} ${control1.y} ${control2.x} ${control2.y} ${end.x} ${end.y}` ``

### Narrow public layout API
- **Where**: `packages/web/src/lib/run-graph/index.ts`
- **Pattern**: `layout` is the only runtime export. Public contracts are `export type` only. Downstream stories import `layout` from `./index` or `@/lib/run-graph`, not `buildRoutes`/`computePositions`.
- **Example**: `export { layout } from './layout';`

### layout last-state-wins
- **Where**: `packages/web/src/lib/run-graph/layout.ts`
- **Pattern**: Forward every node id to `computePositions` (first appearance wins position). Overwrite `states[id]` while iterating so the last duplicate `nodeState` classifies `taken`.
- **Example**: `states[node.id] = node.nodeState;`

### Fail-fast Map lookups
- **Where**: `packages/web/src/lib/run-graph/positions.ts`
- **Pattern**: `@typescript-eslint/no-non-null-assertion` forbids `map.get(k)!`. Use a typed helper that throws if the key is missing. Do not `?? 0` — that hides a missing entry.
- **Example**: `requiredMapValue(layer, id)`

### Barycenter empty-neighbor rule
- **Where**: `packages/web/src/lib/run-graph/positions.ts`
- **Pattern**: Two complete sweeps (top-down predecessors, then bottom-up successors). A node with no neighbors in that direction keeps its current layer index; equal barycenters break on original first-seen index. The ux-mockup returns `0` for empty neighbors — do not copy that.
- **Example**: `if (neighbors.length === 0) return requiredMapValue(positionInLayer, id);`

### Pure run-graph module
- **Where**: `packages/web/src/lib/run-graph/`
- **Pattern**: Zero-dependency TypeScript. No React, DOM, `@xyflow/react`, `@dagrejs/dagre`, or `@/lib/api` imports. Types live in `types.ts`; numeric layout values live in `constants.ts`.
- **Example**: `export const SIDE_PORT_THRESHOLD = NODE_WIDTH * 0.75;` (equals 135)

### Exhaustive NodeState switches
- **Where**: `packages/web/src/lib/run-graph/taken-path.ts`
- **Pattern**: Switch on `NodeState | undefined` with explicit true/false cases so adding a state is a compile error.
- **Example**: `isEdgeTaken` delegates to `isOnPath(targetState)` (target-started rule).

### Web unit tests
- **Where**: `packages/web/src/lib/*.test.ts`
- **Pattern**: `import { describe, expect, test } from 'bun:test'`. Run scoped with `( cd packages/web && bun test src/lib/run-graph/<file>.test.ts )`.
- **Gotcha**: This worktree has no `node_modules` until `bun install`; `bun test` of pure files still runs, but `tsc`/`eslint` fail without the install.
