## Codebase Patterns

### Deep-link once-per-entry is a marker, not a close
- **Where**: `packages/web/src/lib/execution-room-model.ts` (`applyRoomDeepLink`, `closeRoom`)
- **Pattern**: `appliedDeepLinkNode` records the current query value. A matching query after `closeRoom` is a no-op; `null` clears only the marker so a later identical query can open again. `closeRoom` must not wipe `lastExplicitRowByNode` or `scrollTopByScope`.
- **Example**: `if (state.appliedDeepLinkNode === queryNode) return state;`

### Happy-dom getBoundingClientRect stubs
- **Where**: `packages/web/src/lib/use-container-split-mode.test.tsx`
- **Pattern**: happy-dom's `HTMLElement.prototype.getBoundingClientRect` returns a branded `DOMRect`. Assigning a plain object fails `tsc`. Replace the property with `Object.defineProperty` and restore the original descriptor.
- **Example**: `Object.defineProperty(win.HTMLElement.prototype, 'getBoundingClientRect', { configurable: true, value: () => ({ width }) });`

### Execution header fields come only from the selected row
- **Where**: `packages/web/src/lib/execution-room-model.ts` (`buildExecutionHeader`, `runtimeForSelection`)
- **Pattern**: Timing and provider/model are taken from the selected row and its matching `node_started` event. Do not scan sibling rows with `rows.some`. Occurrence selections may carry `retryEpoch`/`iteration` for `Attempt N` / `Iteration N` labels.
- **Example**: `durationMs: input.row.durationMs ?? null`

### Compose text and tool projectors
- **Where**: `packages/web/src/lib/agent-history.ts` (`buildAgentHistory`)
- **Pattern**: Call `projectToolTranscript(projectTextTranscript(rows))` instead of reimplementing delta/snapshot folding or call/result pairing.
- **Example**: `const projected = projectToolTranscript(projectTextTranscript(input.rows));`

### Tool outcome/exit_code live outside generated OpenAPI metadata
- **Where**: `packages/web/src/lib/agent-history.ts` (`extraToolFields`)
- **Pattern**: `WorkflowNodeMessage` metadata in `api.generated.d.ts` omits `outcome` and `exit_code` even though `nodeTranscriptMetadataSchema` has them. Read those fields through `asRecord(row.metadata)`.
- **Example**: `const record = asRecord(row?.metadata); recordedExitCode(record.exit_code);`

### Live AbortSignal must be read through a helper
- **Where**: `packages/web/src/lib/node-message-pages.ts` (`isAborted`)
- **Pattern**: `args.signal?.aborted === true` narrows the live `aborted` flag for the rest of the function, so a later loop check is a TS2367. Read it in a helper so each call is independent.
- **Example**: `function isAborted(signal: AbortSignal | undefined): boolean { return signal?.aborted === true; }`

### Call-signature loader types
- **Where**: `packages/web/src/lib/node-message-pages.ts` (`NodeMessageLoader`)
- **Pattern**: ESLint `@typescript-eslint/prefer-function-type` rejects `interface { (...): T }`. Use `export type Fn = (...) => T`.
- **Example**: `export type NodeMessageLoader = (runId: string, nodeId: string, options: {...}) => Promise<NodeMessagePage>;`

### AbortSignal stays off URLSearchParams
- **Where**: `packages/web/src/lib/api.ts`, `packages/web/src/experiments/console/skills/runs.ts`
- **Pattern**: Destructure `signal` out of list-query options, then pass `{ signal }` only when it is defined. Putting `AbortSignal` into `URLSearchParams` serializes junk and fails the abort tests.
- **Example**: `const { signal, ...queryFields } = options ?? {}; return fetchJSON(url, signal === undefined ? undefined : { signal });`

### NodeMessage wire mapper must switch on kind
- **Where**: `packages/server/src/routes/api.ts` (`toWorkflowNodeMessageResponse`)
- **Pattern**: `z.infer<typeof workflowNodeMessageResponseSchema>` is a discriminated union. Returning a shared object with `kind: row.kind` fails `tsc`. Branch on `row.kind === 'tool' | 'text'` and keep `createdAt` camelCase, assigning `created_at: createdAt`.
- **Example**: `if (row.kind === 'tool') { return { kind: row.kind, payload, created_at: createdAt, ... }; }`

### truncateToolOutput marker can lengthen tiny overages
- **Where**: `packages/server/src/adapters/web/truncate.ts`
- **Pattern**: A 1-char over-cap string becomes longer after truncation because of the KB marker. Cursor tests that assert a shorter list output must use a large overage (`MAX_TOOL_OUTPUT_CHARS + 200_000`). Truncation metadata is response-only — never written back.
- **Example**: `const fullOutput = 'x'.repeat(MAX_TOOL_OUTPUT_CHARS + 200_000);`

### PanelPercent template literals
- **Where**: `packages/web/src/lib/room-split-layout.ts`
- **Pattern**: Build `PanelPercent` with `` `${value}%` `` when `value` is already a `number`. `` `${String(value)}%` `` infers as `` `${string}%` `` and fails `tsc`.
- **Example**: `function percent(value: number): PanelPercent { return \`${value}%\`; }`

### Console happy-dom component tests
- **Where**: `packages/web/src/experiments/console/primitives/console-resizable.test.tsx`, `packages/web/src/experiments/console/components/NodeDivider.test.tsx`
- **Pattern**: Use `installHappyDom` / `restoreHappyDom`. Keep PascalCase components on the module namespace (`consoleResizable.ConsolePanel`) because destructured PascalCase locals fail `@typescript-eslint/naming-convention`. Wrap renders in `await act(async () => { ... })` — `await act(() => { ... })` trips `await-thenable` and `no-confusing-void-expression`.
- **Example**: `createElement(consoleResizable.ConsolePanel, { defaultSize: '60%' }, 'view')`

### Console isolation vs shared layout helpers
- **Where**: `packages/web/src/experiments/console/console-isolation.test.ts`, `eslint.config.mjs`
- **Pattern**: Console production files may import `@/lib/*` except `@/lib/api`. Do not import `@/components/ui/resizable`. `**/*.test.ts` is ESLint-ignored; `**/*.test.tsx` is not. `packages/web/src/components/ui/**` is ESLint-ignored (shadcn).
