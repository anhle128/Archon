## Codebase Patterns

### Graph opener ids live on the node root
- **Where**: `ExecutionDagNode.tsx`, `build-workflow-dag-view-model.ts`, `RunGraphPanel.tsx`
- **Pattern**: View-model data carries `openerId: roomOpenerId('legacy', 'graph', nodeId)`. Legacy puts it on the node root with `tabIndex={-1}`. Console puts it on the existing focusable node button.
- **Example**: `id={roomOpenerId('console', 'graph', node.definition.id)}`

### Header Awaiting input is a button only with a callback
- **Where**: `RunDetailHeader.tsx`, `RunDetailPage.tsx`
- **Pattern**: Render the warning button only when `askAwaiting` and `onAwaitingInput` are both present. The page opens the awaiting execution via `firstPendingAskAwaitingNodeId` and does not switch Log/Graph/Artifacts.
- **Example**: `onInspectSelect(nodeId, undefined, null)`

### parent_platform_id is optional string, not null
- **Where**: `packages/web/src/experiments/console/skills/runs.ts`, `runs.node-messages.test.ts`, `RunDetailPage.test.tsx`
- **Pattern**: OpenAPI types `parent_platform_id` as `string | undefined`. Fixtures that `satisfies RunDetailResponse` cannot assign `null`. Omit the field for the missing case; `getRun` maps it with `?? null`.
- **Example**: `parentPlatformId: res.run.parent_platform_id ?? null`

### Invalidate parent-conversation keys in page tests
- **Where**: `packages/web/src/experiments/console/routes/RunDetailPage.test.tsx`
- **Pattern**: `useEntity(K.parentConversation(...))` caches by `parent-conversation:`. `afterEach` must `invalidate('parent-conversation')` or a later run reuses the previous parent lookup.
- **Example**: `invalidate('parent-conversation');`

### Log sections drain independently of the room
- **Where**: `packages/web/src/experiments/console/components/inspect/ConsoleExecutionHistory.tsx`, `ConsoleInspectPane.tsx`
- **Pattern**: Each `logEntries` section loads its own node messages. Room-only tests that expected `loadMessages` to stay empty while Log is mounted will see plan/loop fetches. Assert the room node was not fetched, or allow stream loads.
- **Example**: `expect(calls.every(([, nodeId]) => nodeId !== 'child')).toBe(true)`

### ConsoleAskCard is parent-owned
- **Where**: `packages/web/src/experiments/console/components/ask/ConsoleAskCard.tsx`, `ConsoleAskCard.test.tsx`
- **Pattern**: Drafts are `draft`/`onDraftChange` like Legacy AskCard. Action tests must re-render from parent state (stateful harness). Other+listed-option text becomes the listed option because Other is derived from the draft value.
- **Example**: `onDraftChange(replaceDraftValue(draft, question.id, option))`

### Console node-message fetch stubs must ignore paging query
- **Where**: `packages/web/src/experiments/console/routes/RunDetailPage.test.tsx` (`stubPageFetch`)
- **Pattern**: `drainNodeMessages` requests `/messages?afterSeq=0&limit=100`. Exact pathname equality misses the call. Compare `path.split('?')[0]` for node-message routes, but keep the full query for `/api/workflows?cwd=`.
- **Example**: `const pathNoQuery = path.split('?')[0] ?? path;`

### applyRoomDeepLink leaves openerId null
- **Where**: `packages/web/src/experiments/console/routes/RunDetailPage.tsx`
- **Pattern**: Shared `applyRoomDeepLink` sets `openerId: null`. Console maps that to `roomOpenerId('console', 'log', rowId)` after apply so Close restores the NodeDivider button.
- **Example**: `openerId: roomOpenerId('console', 'log', next.selection.rowId)`

### Artifacts is a ConsoleInspectPane view
- **Where**: `packages/web/src/experiments/console/components/ConsoleInspectPane.tsx`
- **Pattern**: Do not unmount the inspect pane for Artifacts. Render `ArtifactPanel` as `mainPane` and keep the room docked. `view: 'log' | 'graph' | 'artifacts'`.
- **Example**: `view === 'artifacts' ? <ArtifactPanel runId={run.id} /> : ...`

### Chat AskCard still needs node status for presentation
- **Where**: `packages/web/src/components/workflows/LegacyGraphLogsPane.tsx` (`renderAsk`)
- **Pattern**: `resolveAskCardPresentation` requires `nodeStatus` and `nodeError`. Chat-timeline Ask cards must look them up from `visibleNodeStates` by `interaction.node_id`.
- **Example**: `nodeStatus: visibleNodeStates.find(s => s.nodeId === entry.interaction.node_id)?.status`

### AskDraft types live next to the parser
- **Where**: `packages/web/src/components/workflows/parse-ask-envelope.ts`, `WorkflowExecution.tsx`
- **Pattern**: `AskDraft` / `AskDraftByRequest` are exported from `parse-ask-envelope.ts` (re-exported by AskCard). Import the types from the parser in WorkflowExecution to avoid a circular import.
- **Example**: `import type { AskDraft, AskDraftByRequest } from './parse-ask-envelope';`

### Awaiting-input must not switch tabs
- **Where**: `packages/web/src/components/workflows/WorkflowExecution.tsx` (`WorkflowAskChrome`)
- **Pattern**: `WorkflowAskChrome` still calls `onRequestGraphView()` then `onSelectAwaitingNode`. Parent sets `onRequestGraphView` to a no-op so Awaiting input opens the room without leaving Chat, then rAF-retries `#run-ask-card-{id}`.
- **Example**: `onRequestGraphView={(): void => undefined}`

### Happy-dom querySelector instanceof intersections
- **Where**: `packages/web/src/components/workflows/NodeRoomHeader.test.tsx`, `NodeTranscriptPane.test.tsx`
- **Pattern**: `host` is lib.dom `Element`; `instanceof win.HTMLElement` / `HTMLSelectElement` intersects to `never` because `ELEMENT_NODE` conflicts. Null-check, then `as unknown as HTMLElement`.
- **Example**: `const el = node as unknown as HTMLElement;`

### Drain restart must clear complete
- **Where**: `packages/web/src/components/workflows/NodeTranscriptPane.tsx`
- **Pattern**: `drainNodeMessages` uses `loader` + `state` (not `load`/`initialState`). Live poll and same-scope loader changes must pass `{ ...state, complete: false }` or a completed compatibility page never refetches.
- **Example**: `void runDrain({ ...next, complete: false });`

### Wait for run query data before applyRoomDeepLink
- **Where**: `packages/web/src/components/workflows/WorkflowExecution.tsx`
- **Pattern**: `applyRoomDeepLink` marks `appliedDeepLinkNode` even when no row matches. Calling it while `queryData` is undefined (empty rows) consumes the deep-link and the room never opens after rows load. Skip the effect until `queryData` is defined.
- **Example**: `if (queryData === undefined) return;`

### Percent panel tests need defaultLayout, not defaultSize strings
- **Where**: `packages/web/src/components/workflows/LegacyGraphLogsPane.tsx`
- **Pattern**: happy-dom ignores `defaultSize: '60%'` and falls back to 50/50 flex-grow. Pass `defaultLayout` as `{ 'legacy-run-view': 60, 'legacy-run-room': 40 }` so tests can match 60/40.
- **Example**: `defaultLayout={roomOpen ? { 'legacy-run-view': 100 - ratio, 'legacy-run-room': ratio } : { 'legacy-run-view': 100 }}`

### Same-node graph re-click is canonical, not last-explicit
- **Where**: `packages/web/src/components/workflows/LegacyGraphLogsPane.tsx` (`handleGraphNodeClick`)
- **Pattern**: If the clicked graph node is already selected, pass `null` as lastExplicit so `chooseExecutionForNode` returns the canonical last iteration. Restore last-explicit only when opening a different (or closed) node.
- **Example**: `const lastExplicit = selectedNodeId === nodeId ? null : (lastExplicitRowByNode[nodeId] ?? null);`

### Deep-link once-per-entry is a marker, not a close
- **Where**: `packages/web/src/lib/execution-room-model.ts` (`applyRoomDeepLink`, `closeRoom`)
- **Pattern**: `appliedDeepLinkNode` records the current query value. A matching query after `closeRoom` is a no-op; `null` clears only the marker so a later identical query can open again. `closeRoom` must not wipe `lastExplicitRowByNode` or `scrollTopByScope`.
- **Example**: `if (state.appliedDeepLinkNode === queryNode) return state;`

### Happy-dom getBoundingClientRect stubs
- **Where**: `packages/web/src/lib/use-container-split-mode.test.tsx`
- **Pattern**: happy-dom's `HTMLElement.prototype.getBoundingClientRect` returns a branded `DOMRect`. Assigning a plain object fails `tsc`. Replace the property with `Object.defineProperty` and restore the original descriptor.
- **Example**: `Object.defineProperty(win.HTMLElement.prototype, 'getBoundingClientRect', { configurable: true, value: () => ({ width }) });`

### Execution header fields come only from the selected row
- **Where**: `packages/web/src/lib/execution-room-model.ts` (`buildExecutionHeader`, `runtimeForSelection`)
- **Pattern**: Timing and provider/model are taken from the selected row and its matching `node_started` event. Do not scan sibling rows with `rows.some`. Occurrence selections may carry `retryEpoch`/`iteration` for `Attempt N` / `Iteration N` labels.
- **Example**: `durationMs: input.row.durationMs ?? null`

### Compose text and tool projectors
- **Where**: `packages/web/src/lib/agent-history.ts` (`buildAgentHistory`)
- **Pattern**: Call `projectToolTranscript(projectTextTranscript(rows))` instead of reimplementing delta/snapshot folding or call/result pairing.
- **Example**: `const projected = projectToolTranscript(projectTextTranscript(input.rows));`

### Tool outcome/exit_code live outside generated OpenAPI metadata
- **Where**: `packages/web/src/lib/agent-history.ts` (`extraToolFields`)
- **Pattern**: `WorkflowNodeMessage` metadata in `api.generated.d.ts` omits `outcome` and `exit_code` even though `nodeTranscriptMetadataSchema` has them. Read those fields through `asRecord(row.metadata)`.
- **Example**: `const record = asRecord(row?.metadata); recordedExitCode(record.exit_code);`

### Live AbortSignal must be read through a helper
- **Where**: `packages/web/src/lib/node-message-pages.ts` (`isAborted`)
- **Pattern**: `args.signal?.aborted === true` narrows the live `aborted` flag for the rest of the function, so a later loop check is a TS2367. Read it in a helper so each call is independent.
- **Example**: `function isAborted(signal: AbortSignal | undefined): boolean { return signal?.aborted === true; }`

### Call-signature loader types
- **Where**: `packages/web/src/lib/node-message-pages.ts` (`NodeMessageLoader`)
- **Pattern**: ESLint `@typescript-eslint/prefer-function-type` rejects `interface { (...): T }`. Use `export type Fn = (...) => T`.
- **Example**: `export type NodeMessageLoader = (runId: string, nodeId: string, options: {...}) => Promise<NodeMessagePage>;`

### AbortSignal stays off URLSearchParams
- **Where**: `packages/web/src/lib/api.ts`, `packages/web/src/experiments/console/skills/runs.ts`
- **Pattern**: Destructure `signal` out of list-query options, then pass `{ signal }` only when it is defined. Putting `AbortSignal` into `URLSearchParams` serializes junk and fails the abort tests.
- **Example**: `const { signal, ...queryFields } = options ?? {}; return fetchJSON(url, signal === undefined ? undefined : { signal });`

### NodeMessage wire mapper must switch on kind
- **Where**: `packages/server/src/routes/api.ts` (`toWorkflowNodeMessageResponse`)
- **Pattern**: `z.infer<typeof workflowNodeMessageResponseSchema>` is a discriminated union. Returning a shared object with `kind: row.kind` fails `tsc`. Branch on `row.kind === 'tool' | 'text'` and keep `createdAt` camelCase, assigning `created_at: createdAt`.
- **Example**: `if (row.kind === 'tool') { return { kind: row.kind, payload, created_at: createdAt, ... }; }`

### truncateToolOutput marker can lengthen tiny overages
- **Where**: `packages/server/src/adapters/web/truncate.ts`
- **Pattern**: A 1-char over-cap string becomes longer after truncation because of the KB marker. Cursor tests that assert a shorter list output must use a large overage (`MAX_TOOL_OUTPUT_CHARS + 200_000`). Truncation metadata is response-only — never written back.
- **Example**: `const fullOutput = 'x'.repeat(MAX_TOOL_OUTPUT_CHARS + 200_000);`

### PanelPercent template literals
- **Where**: `packages/web/src/lib/room-split-layout.ts`
- **Pattern**: Build `PanelPercent` with `` `${value}%` `` when `value` is already a `number`. `` `${String(value)}%` `` infers as `` `${string}%` `` and fails `tsc`.
- **Example**: `function percent(value: number): PanelPercent { return \`${value}%\`; }`

### Console happy-dom component tests
- **Where**: `packages/web/src/experiments/console/primitives/console-resizable.test.tsx`, `packages/web/src/experiments/console/components/NodeDivider.test.tsx`
- **Pattern**: Use `installHappyDom` / `restoreHappyDom`. Keep PascalCase components on the module namespace (`consoleResizable.ConsolePanel`) because destructured PascalCase locals fail `@typescript-eslint/naming-convention`. Wrap renders in `await act(async () => { ... })` — `await act(() => { ... })` trips `await-thenable` and `no-confusing-void-expression`.
- **Example**: `createElement(consoleResizable.ConsolePanel, { defaultSize: '60%' }, 'view')`

### Console isolation vs shared layout helpers
- **Where**: `packages/web/src/experiments/console/console-isolation.test.ts`, `eslint.config.mjs`
- **Pattern**: Console production files may import `@/lib/*` except `@/lib/api`. Do not import `@/components/ui/resizable`. `**/*.test.ts` is ESLint-ignored; `**/*.test.tsx` is not. `packages/web/src/components/ui/**` is ESLint-ignored (shadcn).
