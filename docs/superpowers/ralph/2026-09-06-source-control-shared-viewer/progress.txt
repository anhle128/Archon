## Codebase Patterns

### bun run lint can OOM without extra heap
- **Where**: root `package.json` `lint` / `validate`
- **Pattern**: `bun x eslint . --cache --max-warnings 0` can abort with V8 heap OOM (~4 GB) on a cold cache. Retry with `NODE_OPTIONS=--max-old-space-size=8192`. Not a source defect.
- **Example**: `NODE_OPTIONS=--max-old-space-size=8192 bun run validate`

### lint-staged still lints component-integration tests
- **Where**: `packages/web/src/component-integration/source-control-tab.test.tsx`
- **Pattern**: The web package's ESLint ignore for tests does not skip lint-staged (`eslint --no-warn-ignored`). Empty matchMedia/ResizeObserver stubs need `return undefined`, and `RequestInfo` must be narrowed before stringifying.
- **Example**: `if (typeof input === 'string') return input; if (input instanceof URL) return input.href; return input.url;`

### react-resizable-panels v4 sizes are percentage strings
- **Where**: `packages/web/src/components/workflows/source-control/source-control-split.tsx`
- **Pattern**: Numeric sizes are pixels. Pass `"30%"`/`"70%"` strings. Group `orientation="vertical"` stacks list above viewer (`flex-direction: column`); `"horizontal"` is the 900px+ row. Separator has `role="separator"` and `tabIndex={0}`.
- **Example**: `<ResizablePanel defaultSize="30%" minSize="20%" maxSize="70%">`

### Reload waits for the selected-file candidate before exposing stale
- **Where**: `packages/web/src/components/workflows/source-control/source-control-tab.tsx`
- **Pattern**: After the first snapshot, only the Reload callback dispatches `received`. If the selected path remains, finish `loadViewerFile` first, then batch list dispatch and pending-viewer update in the same turn. Stale is list pending OR pending viewer. Same Changes revision never proves content unchanged.
- **Example**: `dispatch({ type: 'received', snapshot: candidate }); setPendingViewer({ file, state: loaded });`

### happy-dom Document is not lib.dom Document
- **Where**: `packages/web/src/components/workflows/source-control/file-viewer.test.tsx`
- **Pattern**: `Window` from happy-dom does not satisfy TypeScript `Document`. Alias `InstanceType<typeof Window>['document']` for parse helpers.
- **Example**: `type HappyDocument = InstanceType<typeof Window>['document']`

### Split diff panes hide the opposite columns
- **Where**: `packages/web/src/components/workflows/source-control/source-control-diff.css`
- **Pattern**: Both trees use `viewType="split"` plus `hunksForSide`. Hide before cols 3–4 and after cols 1–2 at `col` and `.diff-line >` so normal old/new line numbers stay correct.
- **Example**: `.sc-diff-before col:nth-child(n + 3), .sc-diff-before .diff-line > :nth-child(n + 3)`

### happy-dom End-scroll needs listbox scrollHeight
- **Where**: `packages/web/src/component-integration/source-control-tab.test.tsx`
- **Pattern**: TanStack Virtual's last-index `align: "auto"` uses `scrollHeight - clientHeight`. Stub `offsetHeight` 280 before render so fewer than 200 options mount, then after mount patch the listbox instance `clientHeight`/`scrollHeight`/`scrollTop`/`scrollTo` (prototype `scrollTop` is shadowed). Dispatch `scroll` from `scrollTo`.
- **Example**: `listbox.scrollHeight = 200 * 28; listbox.clientHeight = 280;` then End mounts `file-199.ts`

### highlight.js splits escaped HTML tags
- **Where**: `packages/web/src/components/workflows/source-control/syntax-highlight.test.tsx`
- **Pattern**: `highlightAuto('<img ...>')` emits `&lt;<span class="hljs-name">img</span>`. Assert escaped text (`&lt;`) and no real `<img` element; do not require a contiguous `&lt;img` substring.
- **Example**: `expect(html).toContain('&lt;'); expect(html).not.toContain('<img');`

### react-diff-view 3.3.3 ChangeData is a disjoint union
- **Where**: `packages/web/src/components/workflows/source-control/git-hunk-adapter.ts`
- **Pattern**: Map insert/delete to `lineNumber` + one boolean flag, and normal to `oldLineNumber`/`newLineNumber` + `isNormal`. Do not put all three flags on every member. Side filter drops only the opposite insert/delete type and omits empty hunks.
- **Example**: `toChangeData({ type: 'insert', content: 'new', newLine: 2 })` → `{ type: 'insert', content: 'new', lineNumber: 2, isInsert: true }`

### Generate OpenAPI types from the worktree listen port
- **Where**: `packages/web/package.json` `generate:types`
- **Pattern**: The script hardcodes `localhost:3090`. That port is often a different checkout. Start this worktree with an explicit free `PORT`, then run `openapi-typescript http://127.0.0.1:<port>/api/openapi.json`. Do not hand-edit `api.generated.d.ts`. Blank adapter tokens so the typegen server does not poll Slack/Telegram.
- **Example**: `PORT=3791 bun run dev:server` then `bun x openapi-typescript http://127.0.0.1:3791/api/openapi.json -o src/lib/api.generated.d.ts`

### bun lib tests need a window origin stub
- **Where**: `packages/web/src/lib/api.ts` `assertApiResponseOk`
- **Pattern**: Non-2xx formatting uses `new URL(url, window.location.origin).pathname`. `bun test src/lib/` has no `window`. Stub `window.location.origin` in the test file. Prove 200-character truncation with a raw 201-character body, not `JSON.stringify({ error })`.
- **Example**: `Object.assign(globalThis, { window: { location: { origin: 'http://localhost' } } })`

### Omit undefined RequestInit on fetch
- **Where**: `packages/web/src/lib/api.ts` `fetchJSON` / `getWorkflowRunGitFile`
- **Pattern**: `fetchJSON` calls `fetch(url)` when options are undefined. Passing `undefined` as the second argument fails spies that expect one arg. Match that omit-init shape in the raw client.
- **Example**: `options?.signal ? fetch(url, { signal: options.signal }) : fetch(url)`

### Generated GitDiff hunk arrays are mutable
- **Where**: `packages/web/src/lib/api.git-changes.test.ts` `READY_DIFF`
- **Pattern**: `hunks: [] as const` is `readonly []` and fails `tsc` against `GitDiffHunk[]`.
- **Example**: `hunks: [] as GitDiffHunk[]`

### Extract the raw-file wildcard from a fixed marker
- **Where**: `packages/server/src/routes/git/file-handler.ts` `extractEncodedGitFilePath`
- **Pattern**: Take the substring after the first `/git/file/` in `c.req.path`, then `decodeURIComponent` exactly once. Do not rebuild a prefix from the decoded `runId`.
- **Example**: `c.req.path.slice(c.req.path.indexOf('/git/file/') + '/git/file/'.length)`

### Classify git errors structurally in HTTP handlers
- **Where**: `packages/server/src/routes/git/diff-handler.ts` `classifyGitReadError`
- **Pattern**: `GitPathError` / `GitFileError` stay unpublished. Match `name` + `code` on a plain object. Map `invalid_path` → 400 `Invalid file path`, `file_not_found` → 404 `File not found`, else opaque 500.
- **Example**: `candidate.name === 'GitFileError' && candidate.code === 'not_found'`

### Recheck CAP-6 after ready-gate I/O rejection
- **Where**: `packages/server/src/routes/git/changes-handler.ts`, `diff-handler.ts`, `file-handler.ts`
- **Pattern**: If `changedFiles`/`fileDiff`/`fileAt` rejects after a ready gate, call `loadRunCheckout` once more. Empty → HTTP 200 CAP-6; otherwise keep the opaque 500. Diff and file CAP-6 bodies are `{ emptyReason }` only, with no ETag on the file route.
- **Example**: delete the checkout inside the mock then reject → `{ emptyReason: 'no_checkout' }`

### Transport path validation is independent of @archon/git
- **Where**: `packages/server/src/routes/git/path-input.ts`
- **Pattern**: `isValidGitFilePath` validates already-decoded HTTP input. Do not import `parseGitFilePath`. Reject before `loadRunCheckout` / git. Reuse in the raw-bytes route.
- **Example**: `'../x'` is false; `':colon.ts'` is true

### GitFileError and file I/O stay package-private
- **Where**: `packages/git/src/file-read.ts`, `packages/git/src/index.ts`
- **Pattern**: Export only `fileAt`, `fileDiff`, and their data types from `@archon/git`. Keep `GitFileError`, `parseUnifiedDiff`, `hasNulInFirst8k`, and `execFileBufferAsync` internal. Later HTTP stories classify `GitFileError` structurally via `name` + `code`.
- **Example**: `throw new GitFileError('not_found')` with `this.name = 'GitFileError'`

### Tree reads are ls-tree then cat-file blob
- **Where**: `packages/git/src/file-read.ts` `fileAt`
- **Pattern**: `git --literal-pathspecs ls-tree -z TREE -- PATH` then `git cat-file blob BLOB_OID` through `execFileBufferAsync` with unbounded `maxBuffer`. Never `HEAD:path`, `oid:path`, `exec`, or a shell string.
- **Example**: argv `['-C', workingPath, '--literal-pathspecs', 'ls-tree', '-z', 'HEAD', '--', path]`

### mock.module('@archon/git') must stub fileAt and fileDiff
- **Where**: the 31 factories listed in plan Task 2
- **Pattern**: `mock.module` merges omitted exports from the real module. Every existing `@archon/git` factory must stub the two public I/O exports or tests hit real git.
- **Example**: `fileAt: mock(async () => ({ path: 'x.ts', bytes: new Uint8Array(), binary: false, contentHash: '0'.repeat(64) }))`

### Uint8Array is zero-filled
- **Where**: `packages/git/src/file-read.test.ts` `hasNulInFirst8k`
- **Pattern**: `new Uint8Array(n)` is all NULs. Fill with non-zero before placing a late NUL when proving the 8KB window.
- **Example**: `const late = new Uint8Array(9000).fill(1); late[8192] = 0;`

### Internal GitPathError is package-private
- **Where**: `packages/git/src/git-path.ts`
- **Pattern**: `GitPathError`, `parseGitFilePath`, and `containLivePath` are internal `@archon/git` API. Do not export them from `packages/git/src/index.ts`. Later stories classify them structurally (`name` + `code`) because the classes stay internal.
- **Example**: `throw new GitPathError('escape')` with `this.name = 'GitPathError'`

### containLivePath does not catch realpath errors
- **Where**: `packages/git/src/git-path.ts` `containLivePath`
- **Pattern**: Let `realpath` ENOENT (and other filesystem errors) propagate. Callers must distinguish missing files from `GitPathError`. Never wrap `realpath` in try/catch here.
- **Example**: missing `inside.ts` rejects as `Error:ENOENT`, not `GitPathError`

### Path validation is decode-then-segment
- **Where**: `packages/git/src/git-path.ts` `parseGitFilePath`
- **Pattern**: Reject empty, NUL, POSIX `/`, Windows `\`-prefix and `C:\`/`C:/` drive, and any `..` segment after either-slash split. Keep colon, leading dash, glob, space, and newline filenames literal.
- **Example**: `':colon.ts'` and `'-dash.ts'` return unchanged; `'a/../x'` throws `dotdot`
