## Codebase Patterns

### Worktree smoke needs PORT so Vite does not proxy to 3090
- **Where**: `packages/web/vite.config.ts` `apiPort = env.PORT ?? '3090'`
- **Pattern**: Host Archon already occupies 3090. Start this worktree with `PORT=<free> bun run dev:server` and the same `PORT` for Vite so `/api` hits the new git log route. `bun --filter @archon/web dev` can log Local:5173 without binding; start `bun x vite --port 5173 --strictPort --host 127.0.0.1` from `packages/web`.
- **Example**: `PORT=3750 bun run dev:server` then Vite with `PORT=3750`

### Whole-tab CAP-6 hides History
- **Where**: `packages/web/src/components/workflows/source-control/source-control-panel.tsx` `displayedEmptyReason`
- **Pattern**: Union Changes and History `emptyReason`. `container` wins over `no_checkout`. Either reason early-returns the quiet CAP-6 copy and omits the History heading/graph. Ready empty log (`commits: []`, no emptyReason) is `No commits yet` under History, not CAP-6.
- **Example**: `if (reasons.includes('container')) return 'container'`

### Tab History query is independent with combined stale
- **Where**: `packages/web/src/components/workflows/source-control/source-control-tab.tsx`
- **Pattern**: Second `useQuery` keyed `['workflowRunGitLog', runId]` with the same Infinity/no-poll flags as Changes. Own `gitLogSnapshotReducer`. `onReload` `Promise.all`s both refetches. Combined `stale` is true when either snapshot or the viewer has pending AND the selected-file candidate guard still allows accept. Commit activation must not call diff/file.
- **Example**: `const [result, historyResult] = await Promise.all([refetch(), refetchHistory()])`

### mockGitRoutes log branch before unexpected-fetch throw
- **Where**: `packages/web/src/component-integration/source-control-tab.test.tsx`
- **Pattern**: Default `/git/log` to `EMPTY_GIT_LOG` so existing Changes tests stay stable. `onLog` is optional. `requireListbox` must pin `aria-label="Uncommitted changes"`. Complete URL equality assertions filter `/git/log`. Direct panel renders pass `historySnapshot` + `historyLoadState`.
- **Example**: `if (url.includes('/git/log')) { logCall += 1; ... }`

### History graph is SVG + listbox, not React Flow
- **Where**: `packages/web/src/components/workflows/source-control/commit-history-graph.tsx`, `commit-graph-row.tsx`
- **Pattern**: Reuse Changes' `useVirtualizer` (`estimateSize` 24, `initialRect` height 280, overscan 8). `nextCommitIndex` mirrors `nextChangedFileIndex`. Rows are `role="option"` buttons. SVG width `laneCount * 12`, height 24; `data-edge="through|incoming|parent"`; circle vs diamond polygon; `stroke-text-secondary` / `fill-text-primary`; never opacity. `aria-label` is `${isMerge ? 'Merge commit' : 'Commit'} ${shortOid}: ${subject}; ${authorName}; ${relativeTime}`. Do not import `@xyflow/react`.
- **Example**: `useVirtualizer({ count, estimateSize: () => COMMIT_ROW_HEIGHT, initialRect: { width: 0, height: 280 }, overscan: 8 })`

### History freeze reducer is a deliberate duplicate of Changes
- **Where**: `packages/web/src/components/workflows/source-control/source-control-state.ts` `gitLogSnapshotReducer`
- **Pattern**: Do not extract a shared snapshot reducer. Rule of Three: copy the freeze/pending/accept transitions beside `sourceControlSnapshotReducer`. Fingerprint ready History as `ready:${revision}` and CAP-6 as `empty:${emptyReason}` so an empty unborn log never collides with `no_checkout`/`container`. `toGitLogSnapshot` also copies `truncated`.
- **Example**: `gitLogSnapshotReducer(INITIAL_GIT_LOG_STATE, { type: 'received', snapshot })`

### assignCommitLanes is pure topology, not one-lane-per-branch
- **Where**: `packages/web/src/components/workflows/source-control/commit-lanes.ts`
- **Pattern**: Newest-first git log order. `active: (string | null)[]` is the next oid each lane is waiting to paint. Incoming = reservations matching this oid; through = other non-null reservations. Place on smallest incoming, else first null, else append. Clear incoming before placing parents in `%P` order. First parent reuses this commit's lane when free; later parents reuse an existing reservation, a null slot, or append. Root commits leave no outgoing reservation. `laneCount` is one more than the max lane index. No React/DOM.
- **Example**: `assignCommitLanes([{ oid, parents }])` → `{ rows: [{ oid, lane, incomingLanes, throughLanes, parentLanes, isMerge }], laneCount }`

### Git log client mirrors getWorkflowRunGitChanges
- **Where**: `packages/web/src/lib/api.ts` `getWorkflowRunGitLog`
- **Pattern**: Same `fetchJSON` + `encodeURIComponent(runId)` + optional `{ signal }` RequestInit. No `working_path`. Re-export `GitLogResponse`/`GitLogCommit` next to the other git types. Client tests append to `api.git-changes.test.ts`.
- **Example**: `return fetchJSON(\`/api/workflows/runs/${encodeURIComponent(runId)}/git/log\`, options?.signal ? { signal: options.signal } : undefined);`

### generate:types needs this worktree's OpenAPI, not port 3090
- **Where**: `packages/web/package.json` `generate:types` hardcodes `http://localhost:3090/api/openapi.json`
- **Pattern**: Host Archon on 3090 is a different checkout and lacks new routes. Start `PORT=<free> bun run dev:server` from this worktree and run `bun x openapi-typescript http://127.0.0.1:<port>/api/openapi.json -o src/lib/api.generated.d.ts` from `packages/web`. Do not kill the process on 3090.
- **Example**: `PORT=3191 bun run dev:server` then `bun x openapi-typescript http://127.0.0.1:3191/api/openapi.json -o src/lib/api.generated.d.ts`

### Git log route mirrors changes CAP-6 handler
- **Where**: `packages/server/src/routes/git/log-handler.ts`, registered in `packages/server/src/routes/api.ts` immediately after changes
- **Pattern**: Same `loadRunCheckout` gate as changes: 404 on missing run, 200 CAP-6 empty envelope (`container`/`no_checkout`) before any git probe, post-read recheck on thrown git error, opaque 500 `{ error: 'Could not read git history' }` with `errorType` only. Paired Pino `git.log_started` then `git.log_completed`/`git.log_failed`. Do not call `requireWebUser`.
- **Example**: `registerOpenApiRoute(gitLogRoute, async c => handleGitLog(c, apiError));`

### Git log HTTP tests share api.git-changes.test.ts
- **Where**: `packages/server/src/routes/api.git-changes.test.ts` (`mockLog`, `expectGitLogPair`)
- **Pattern**: Keep `mockLog` configurable from US-001. Helpers `gitLogCalls`/`expectGitLogPair` sit beside `expectFileLogPair`. Tests must stay in this isolated process — `bun --filter @archon/server test` already splits it.
- **Example**: `expectGitLogPair('git.log_completed', { runId: 'run-1', commitCount: 1 });`

### @archon/git mock.module factories must stub new exports
- **Where**: 31 `mock.module('@archon/git')` factories listed in plan Task 1 Step 4
- **Pattern**: Bun `mock.module()` merges omitted exports from the real module. A new public export like `log` will hit live git unless every factory stubs it.
- **Example**: `log: mock(async () => ({ commits: [], revision: '0'.repeat(64), truncated: false })),`

### Git exec error text uses Error & { stderr?: string }
- **Where**: `packages/git/src/git-log.ts` `errorText`, matching `packages/git/src/repo.ts` / `worktree.ts`
- **Pattern**: Do not type `message`/`stderr` as `unknown` then `String(...)` — `@typescript-eslint/no-base-to-string` fails. Cast to `Error & { stderr?: string }` and interpolate.
- **Example**: `const err = error as Error & { stderr?: string }; return \`${err.message} ${err.stderr ?? ''}\`;`

### Fresh worktree needs bun install before bun --filter tests
- **Where**: package scripts such as `bun --filter @archon/git test`
- **Pattern**: Filter runs from the package directory and cannot resolve workspace deps without `node_modules`. `bun test packages/git/src/git-log.test.ts` from repo root can still pass because git-log itself does not import `@archon/paths`.
