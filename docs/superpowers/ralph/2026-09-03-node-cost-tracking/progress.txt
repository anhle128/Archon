## Codebase Patterns


### Usage report query is dialect-safe ledger aggregates
- **Where**: `packages/core/src/db/usage-report.ts`, `packages/core/src/schemas/usage-report.ts`
- **Pattern**: CamelCase `usageReportSchema` via z.infer. `queryUsageReport` joins ledger→event→run→codebase; accounting time is `e.created_at`. Defaults: no dates/runId → current UTC month; runId alone → entire run (`from`/`to` null). Fetch LIMIT 501 and throw overflow (never silent truncate). Coverage uses only date/project/run/node filters. GROUP BY/ORDER BY only from exhaustive enum switch + NULLS FIRST. Convert PG bigint/count strings with MAX_SAFE_INTEGER rejection; keep null sums distinct from zero; no effective USD total.
- **Example**: `usageDb.queryUsageReport({ runId, groupBy: 'node' })`

### Usage recorder is a narrow port with atomic event+ledger writes
- **Where**: `packages/workflows/src/usage.ts`, `packages/core/src/workflows/usage-recorder.ts`, `packages/core/src/db/workflow-events.ts`
- **Pattern**: Required `WorkflowDeps.usageRecorder` (not on IWorkflowStore). Validate + materialize estimates + generate event id BEFORE `withTransaction`. Insert `node_usage_recorded` + N ledger rows atomically. On tx failure: one event-only fallback with same id + `ignoreDuplicateId` (ON CONFLICT DO NOTHING). Never throw, never outbox, never put estimates in event JSON.
- **Example**: `insertWorkflowEvent(query, { id, event_type:'node_usage_recorded', ... }, { ignoreDuplicateId: true })`

### Global pricing is exact-match nested maps, ledger-only
- **Where**: `packages/core/src/usage/estimate.ts`, `packages/core/src/config/config-types.ts`
- **Pattern**: `pricing` lives only on `GlobalConfig` (not Repo/Merged/Safe). Lookups are nested `Map<provider, Map<model, rates>>` — never `${provider}/${model}`. Precedence: reported `costUsd` (incl. 0) → exact config pair → exact Pi catalog provider/id → none. Invalid/duplicate config pairs are blocked so catalog cannot price them. Require input+output token counts; positive category without rate → whole estimate null; zero-count categories may omit that rate; tiers use Pi `aggregate > inputTokensAbove` rule. Resolve lookups before any DB transaction.
- **Example**: `materializeUsageCost(entry, lookups) → { cost_usd, cost_estimated_usd, pricing_source }`

### updateGlobalConfig preserves unknown GlobalConfig keys via spread
- **Where**: `packages/core/src/config/config-loader.ts` `updateGlobalConfig`
- **Pattern**: `{ ...current }` then copy only known mutation fields. Omit `pricing` from the updates type so API/settings cannot write it; operator-authored `pricing` survives assistants/tiers patches because it is never deleted.
- **Example**: `updates: Partial<Omit<GlobalConfig, 'tiers' | 'aliases' | 'pricing'>> & { tiers?, aliases? }`


### Usage ledger is event-owned and constraint-dense
- **Where**: `migrations/000_combined.sql`, `packages/core/src/db/adapters/sqlite.ts`, `packages/core/src/schemas/usage-ledger.ts`
- **Pattern**: 17-column child of workflow_events with cascade delete; no duplicated run/node/workflow identity columns; CHECK enforces measure presence, cost mutual exclusion, pricing_source↔estimate coupling, model_source/model nullability, reasoning≤output; indexes live in PG trailing section and SQLite createSchema for brand-new tables.
- **Example**: `UNIQUE(workflow_event_id, entry_index)` + `ON DELETE CASCADE`


### Workflow usage event is internal snake_case + boundary-validated
- **Where**: `packages/workflows/src/schemas/usage-breakdown.ts`, `packages/workflows/src/store.ts`
- **Pattern**: `node_usage_recorded` is WORKFLOW_EVENT_TYPES-only (never INTERNAL_EVENT_TYPE_MAP / DASHBOARD_SOURCE_EVENT_TYPES). CamelCase Zod mirrors provider contract with ExactMatch→false AssertTrue compile check; persisted payload is snake_case via `buildNodeUsageRecordedEventData`. `validateProviderUsageAtBoundary` keeps valid entries in order, logs index/issue only, returns null when none remain (no event write). step_name stays on the event row (namespaced for loop_group bodies), not inside data.
- **Example**: `validateProviderUsageAtBoundary(entries) → { breakdown, rejected } | null`


### OMP hidden usage is post-exit and fail-soft
- **Where**: `packages/providers/src/community/omp/session-usage.ts`, `provider.ts`
- **Pattern**: Snapshot before resume/fork spawn; after exit resolve destination session artifact dir; parse only advisor/subagent JSONL via verified open + bounds; never change isError on transcript failures.
- **Example**: `maybeEnrichResult(result, { env, cwd, noSession, snapshot })`


### Provider usage contract is additive and package-local
- **Where**: `packages/providers/src/types.ts`, `packages/providers/src/usage-breakdown.ts`
- **Pattern**: Add `usageBreakdown?: UsageBreakdown` beside retained `modelUsage`; validate entries in providers only (no workflow/core imports). Missing measures stay `undefined`; known zeros survive; forbidden estimate/context fields are rejected by key name without logging payloads.
- **Example**: `normalizeUsageBreakdown(entries)` returns `{ breakdown, rejected: [{ index, issue }] }`.

### Observability span model never guesses from multi-model usage
- **Where**: `packages/providers/src/observability.ts` `resolveModel`
- **Pattern**: Prefer terminal `resolvedModel.id`, then effective `options.model`, then `assistantConfig.model`, else absent. Do not read `modelUsage` / `usageBreakdown` keys for the span model attribute.
- **Example**: Multi-model result without `resolvedModel` leaves generation model undefined.

### Providers package test isolation
- **Where**: `packages/providers/package.json` `scripts.test`
- **Pattern**: Each new test file gets its own `bun test <file>` invocation chained with `&&` to avoid `mock.module` pollution.
- **Example**: `bun test src/usage-breakdown.test.ts && bun test src/observability.test.ts`

### Claude usage-bearing API failures yield terminal isError with accumulated usage
- **Where**: `packages/providers/src/claude/provider.ts` sendQuery retry loop + `ClaudeApiResultError`
- **Pattern**: Normalize `modelUsage` before API-failure throw; attach `usageBreakdown` on `ClaudeApiResultError`; accumulate across retries; on final typed API failure with usage, yield `isError` result and return (preserve throw when no usage). Merge prior retry usage into successful terminal results.
- **Example**: rate_limit with modelUsage → 4 attempts → one result chunk with 4 breakdown rows

### Grok multi-model usage never apportions aggregates
- **Where**: `packages/providers/src/grok/event-parser.ts` `buildUsageBreakdown`
- **Pattern**: One valid model gets aggregate tokens/USD/requests; multiple models get requests-only rows + one `model: null`/`unknown` aggregate row; no model uses requested model when known else unknown.
- **Example**: two modelCalls keys + usage → two requests rows + one unknown aggregate

### Codex cache subtraction keeps legacy total input
- **Where**: `packages/providers/src/codex/provider.ts` `extractUsageFromCodexEvent`
- **Pattern**: `TokenUsage.input` stays SDK `input_tokens`; breakdown `inputTokens = max(input - cached, 0)` with `cacheReadTokens = cached`; reasoning is subset of output; no requests/USD.
- **Example**: 100/40 cached → legacy input 100, breakdown inputTokens 60


### OpenCode cost must sum distinct assistant messages
- **Where**: `packages/providers/src/community/opencode/session.ts`, `multi-agent.ts`, `tokens.ts`
- **Pattern**: Map assistant info by message id (replace on repeat). At idle, sum `normalizeTokens` for legacy totals and emit one `usageBreakdown` row per id. Top-level `cost` MUST equal `tokens.cost` (sum), because dag-executor accounts only `msg.cost` and discards `tokens.cost`. Reasoning is an output subset — never add it into total again. Multi-agent rows set `kind: 'subagent'`.
- **Example**: two ids cost 0.2 + 0.05 → `tokens.cost` and `cost` both 0.25

### Copilot usage accumulates; multiplier is not USD
- **Where**: `packages/providers/src/community/copilot/event-bridge.ts`
- **Pattern**: Capture every `assistant.usage` into arrays; sum legacy TokenUsage; normalize each entry with `provider: github-copilot`, `requests: 1`, optional cache/reasoning. Ignore `data.cost` (multiplier). `kind: subagent` only for non-empty `parentToolCallId`; never from free-form `initiator`.
- **Example**: two usage events → two breakdown rows; cost field omitted

### Pi catalog cost includes cache + optional tiers
- **Where**: `packages/providers/src/community/pi/model-catalog.ts`, `packages/server/src/routes/schemas/provider.schemas.ts`
- **Pattern**: Expose `cacheRead`/`cacheWrite` always; map SDK `tiers` when present. Route schema requires the cache fields; tiers optional.
- **Example**: `{ input, output, cacheRead, cacheWrite, tiers?: [{ inputTokensAbove, ... }] }`
