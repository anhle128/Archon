## Codebase Patterns

### Native Ralph YAML contract vs stale test literals
- **Where**: `.archon/workflows/defaults/speckit-ralph-native-feature.yaml` (`ralph-loop-run`: `omp` + `xai-oauth/grok-4.5` @ `high`); `packages/workflows/src/dag-executor.test.ts`; `packages/workflows/src/loader.test.ts`
- **Pattern**: Native Ralph model/effort assertions must copy the YAML, not older alibaba/max literals. Dual-model: first loop `xai-oauth/grok-4.5` @ `high`, final loop `anthropic/claude-sonnet-5` @ `xhigh`.
- **Example**: `expect(loopNode?.model).toBe('xai-oauth/grok-4.5'); expect(options.nodeConfig?.effort).toBe('high');`

### Plannotator fake control files need atomic replace
- **Where**: `packages/workflows/src/plannotator-gate-executor.test.ts` `releaseDecision`
- **Pattern**: `existsSync(control)` then `JSON.parse(readFileSync(control))` races with truncating `writeFileSync`. Write temp then `renameSync`.
- **Example**: `writeFileSync(temporary, json); renameSync(temporary, controlPath);`

### Permission HTTP confirm does not auto-dispatch
- **Where**: `packages/server/src/routes/api.ts` (`confirmPermissionRoute` after `answerAskHumanRoute`)
- **Pattern**: Mirror Ask's pre-validation `app.use` 401 middleware and typed error mapping, but do not call `tryAutoResumeAfterGate` / `dispatchToOrchestrator` / `resumeWorkflowRun`. Unexpected failures log `{ errorName, runId, callId }` only — never `err` or intent. OpenAPI body is `permissionConfirmRequestSchema = permissionConfirmBodySchema.openapi('PermissionConfirmBody')`.
- **Example**: `registerOpenApiRoute(confirmPermissionRoute, ...)` then return remaining-pending message without orchestrator dispatch.

### Permission operations keep distinct auth/log helpers from Ask
- **Where**: `packages/core/src/operations/workflow-operations.ts` (`confirmPermission` after `answerAskHuman`)
- **Pattern**: Do not reuse Ask error classes. Permission lookup logs `{ errorName, runId }` and throws `Failed to look up workflow run <runId>` without the raw DB message. Auth is starter-only (`run.user_id === actorUserId`); empty string and undefined both throw `PermissionAuthenticationRequiredError`. Log/emit only after `confirmPendingPermission` resolves, identifiers only.
- **Example**: `getLog().error({ errorName, runId }, 'operations.workflow_permission_lookup_failed')` then `workflow.permission_resolved` + `interaction_resolved` after commit.

### Parallel StrReplace truncates large files
- **Where**: `packages/cli/src/commands/workflow.test.ts` (~10k lines)
- **Pattern**: Concurrent StrReplace on one large file can wipe the tail. Restore from git and apply sequential in-process replacements. `mock.module()` MERGES, so every pending-interactions factory that can import operations must export `confirmPendingPermission`.
- **Example**: Python `text.replace(old, new, 1)` after `count == 1`, then `git checkout --` if the file shrinks.

### Permission confirm duplicates Ask transaction, no generic resolver
- **Where**: `packages/core/src/db/workflow-pending-interactions.ts` (`confirmPendingPermission` after `resolvePendingInteraction`)
- **Pattern**: Keep Ask and Permission transaction bodies explicit. Same lock/CAS/resume (`'paused-ask'`) shape; kind check, event payload, and body validation differ. Do not extract a two-caller generic resolver (rule of three). Event data is identifiers only: `{ node_id, tool_use_id, kind: 'permission', resumed }` — never intent/envelope/answer.
- **Example**: `if (current.kind !== 'permission') throwValidation('kind_not_permission')` then CAS + optional `resumeWorkflowRunInTransaction(..., 'paused-ask')`.

### Permission confirm schemas live next to Ask contracts
- **Where**: `packages/workflows/src/schemas/pending-interaction.ts`
- **Pattern**: Engine-owned Zod schemas use `z` from `@hono/zod-openapi`, `.strict()`, and `z.infer` — never parallel hand-written types. Permission confirm body is `{ intent: string }` with `trim().length > 0` refinement; submitted whitespace is preserved. Persistence input is a separate strict schema wrapping that body.
- **Example**: `permissionConfirmBodySchema` + `confirmPendingPermissionInputSchema` immediately after `AskAnswerBody`, before `resolvePendingInteractionInputSchema`.

### Test files are ESLint-ignored
- **Where**: `packages/workflows/src/schemas/pending-interaction.test.ts`
- **Pattern**: `eslint --max-warnings 0` on `*.test.ts` warns "File ignored because of a matching ignore pattern". Lint production files only, or pass `--no-warn-ignored`. Pre-commit already uses `--no-warn-ignored`.
