## Codebase Patterns

### Opt-in DeepSeek ACP live spike
- **Where**: `packages/providers/src/community/deepseek/acp-handshake-spike.ts`, `packages/providers/package.json` `spike:deepseek:acp`
- **Pattern**: Skip with exit 0 unless `DEEPSEEK_LIVE_TEST=1`. When enabled, require `DEEPSEEK_API_KEY`, `DEEPSEEK_BASE_URL`, and `DEEPSEEK_LIVE_MODEL` without printing values. Fresh prompt `Reply with exactly pong.` then resume `Reply with exactly pong again.` and require a non-error result plus `resumed: true`. Print only skip/pass/generic-fail. Keep the script out of `test` and `validate`.
- **Example**: `bun run spike:deepseek:acp` → `DeepSeek ACP live spike skipped (set DEEPSEEK_LIVE_TEST=1 to run).` exit 0

### Large markdown surgical edits
- **Where**: `packages/docs-web/src/content/docs/getting-started/ai-assistants.md`
- **Pattern**: Exact-string Python replace with a post-edit length assertion. Line-anchored and some exact-replace editors truncated this 1006-line file to 302 lines. Restore from git if `wc -l` drops.
- **Example**: `apply(path, [(old, new)], min_delta=1500)` then `git checkout --` on shrink

### Community provider registration without eager ACP
- **Where**: `packages/providers/src/community/deepseek/registration.ts`, `packages/providers/src/registry.ts`
- **Pattern**: Idempotent `isRegisteredProvider('deepseek')` guard, `builtIn: false`, vendor `deepseek` API-key spec. One import + `registerDeepseekProvider()` in `registerCommunityProviders()` immediately before the env-gated fake. Root and community barrels re-export `DeepseekProvider`, `parseDeepseekConfig`, `registerDeepseekProvider`, `DEEPSEEK_CAPABILITIES`, and `DeepseekProviderDefaults`. Lazy-load test mocks only `@agentclientprotocol/sdk` with a factory counter (do not mock `@deepseek-ai/dsh`), then dynamically imports registration/provider and instantiates — never `sendQuery()`. `provider-lazy-load.test.ts` is its own last DeepSeek `bun test` invocation. Loader tests register in the case and restore `registerBuiltinProviders()` + `registerOmpProvider()` in `finally` after `clearRegistry()`.
- **Example**: `registerDeepseekProvider()` / `new DeepseekProvider()` leaves ACP SDK load count at 0


### DeepSeek provider error-as-result + lazy ACP import
- **Where**: `packages/providers/src/community/deepseek/provider.ts`
- **Pattern**: Store injected `DeepseekProviderDependencies` only. Check `abortSignal.aborted` before parse/env/MCP/runner. Capture the resolved API key for redaction after `buildDeepseekChildEnv`. Dynamic `import('./acp-client')` happens after preflight when `runTurn` is not injected — type-only `DeepseekProcessInput` import is erased. Wrap the runner with `withResumedOutcome(stream, resumedOutcome(resumeSessionId, true))`; resume failures throw `deepseek_resume_failed` and the outer catch yields one error result (never `session/new`). Dedup MCP `missingVars` into one system warning.
- **Example**: `new DeepseekProvider({ runTurn, resolveNodeBinary, resolveDshEntrypoint })`

### ACP connectWith plus queue streaming
- **Where**: `packages/providers/src/community/deepseek/acp-client.ts`
- **Pattern**: Start `client({ name: 'archon-deepseek' }).connectWith(...)` without awaiting. Pipe success to `queue.close()` and failure to `queue.fail()`, then `for await` the queue so session updates are readable before prompt settlement. Cancel with `ctx.notify(methods.agent.session.cancel)` — never `request()`. Wrap resume failures as `deepseek_resume_failed` before the outer `deepseek_protocol_error` catch. Fake `SetSessionConfigOption` handlers must return `{ configOptions: [] }`. Injected FakeChild `kill()` must emit `exit` synchronously so `terminateGraceMs: 0` does not SIGKILL a child that already honored SIGTERM.
- **Example**: `driveDeepseekAcpTurn(agentApp, input)` / `runDeepseekAcpTurn(processInput, { spawn, terminateGraceMs: 0 })`

### AsyncQueue single waiter and one terminal
- **Where**: `packages/providers/src/community/deepseek/async-queue.ts`
- **Pattern**: One `QueueWaiter` slot and one `closed | failed` terminal. `push` resolves a waiting reader immediately; otherwise enqueue. `close`/`fail` drain the buffer before `done: true` or reject, and are idempotent. `push` after terminal throws. Do not `Promise.reject(unknown)` — `@typescript-eslint/prefer-promise-reject-errors` fails; reject through `QueueWaiter.reject` so `fail(error: unknown)` keeps identity.
- **Example**: `new AsyncQueue<T>()` then `push` / `close` / `fail`

### Strict MCP translation (no skip, no mutation)
- **Where**: `packages/providers/src/community/deepseek/mcp.ts`
- **Pattern**: `import type { McpServer }` only. Omitted `type` is stdio. Bare commands resolve with `which`/`where` against the supplied `PATH`; absolute commands stay unchanged after a POSIX `X_OK` / Windows regular-file check. Stdio ACP shape has no `type` field; HTTP includes `type: 'http'`. SSE and unknown transports throw `deepseek_mcp_config_error`. Never mutate input objects; clone `args` and convert env/headers into new `{ name, value }[]`.
- **Example**: `buildDeepseekMcpServers(servers, env)`

### Stateful ACP SessionUpdate translation (no fabricated usage)
- **Where**: `packages/providers/src/community/deepseek/event-bridge.ts`
- **Pattern**: `mapDeepseekSessionUpdate` uses an exhaustive `switch (update.sessionUpdate)` with a `never` default. Tool start stores `{ name, input }` by `toolCallId`; in-progress updates mutate that entry; `completed`/`failed` emit `tool_result` then `delete`. `usage_update` (even with `cost`) and other housekeeping variants emit `[]` — never `tokens`/`usageBreakdown`/`cost`. Non-text message/thought content is ignored, not stringified.
- **Example**: `mapDeepseekSessionUpdate(update, createDeepseekEventState())`

### Isolated child-env records (never mutate process.env)
- **Where**: `packages/providers/src/community/deepseek/env.ts`
- **Pattern**: `buildDeepseekChildEnv` takes `ambient`/`request` records. Tests pass isolated objects; never mutate `process.env`. Request overlays ambient, then config `baseUrl`, then `DSH_PERMISSION_MODE`. Empty/missing `DEEPSEEK_API_KEY` throws `deepseek_missing_api_key` without trimming or logging the value. Never writes `DSH_PROVIDER_ROUTE`.
- **Example**: `buildDeepseekChildEnv({ ambient, request, baseUrl, permissionMode })`

### Injectable DeepSeek runtime facts
- **Where**: `packages/providers/src/community/deepseek/node-resolver.ts` `DeepseekRuntimeFacts`
- **Pattern**: Inject `isBinary`/`execPath`/`isNodeHost`/`platform`/`findNodeOnPath` so tests cover POSIX vs Windows without changing `process.platform` or spawning a shell. POSIX uses `X_OK`; Windows only requires a regular file. Binary mode throws `deepseek_runtime_unavailable` before `createRequire()`.
- **Example**: `resolveDeepseekNodeBinary(configNodeBin, env, facts)`

### Typed DeepSeek errors + redaction
- **Where**: `packages/providers/src/community/deepseek/errors.ts`
- **Pattern**: `DeepseekProviderError(subtype, message)`. `toDeepseekErrorResult` keeps known subtypes, maps unknown to `deepseek_acp_error`, replaces every secret occurrence with `[REDACTED]`, and never synthesizes tokens/usage/cost/sessionId.
- **Example**: `toDeepseekErrorResult(error, [apiKey])` → `{ type: 'result', isError: true, errorSubtype, errors: [sanitized] }`

### DeepSeek config parser fail-fast + applied defaults
- **Where**: `packages/providers/src/community/deepseek/config.ts`
- **Pattern**: `parseDeepseekConfig` always returns `profile`/`providerRoute`/`permissionMode` defaults. Explicit `providerRoute` without `model` is rejected; the default route is allowed without a model. `maxTokens !== undefined` throws `DeepseekProviderError('deepseek_unsupported_config', ...)` with the pinned-ACP message.
- **Example**: `'assistants.deepseek.maxTokens is unsupported: pinned DSH ACP exposes only model and reasoning_effort.'`

### DeepSeek effort switch (not clampEffort)
- **Where**: `packages/providers/src/community/deepseek/config.ts` `resolveDeepseekEffort`
- **Pattern**: Use an explicit `switch`, not `clampEffort`. Map `minimal->off`, `medium->low`, `xhigh->high`; preserve `off`/`low`/`high`/`max`; throw on blank/unknown. `off` is not on `EFFORT_LADDER`.
- **Example**: `resolveDeepseekEffort('minimal') === 'off'`

### Exact provider dependency pins
- **Where**: `packages/providers/package.json`
- **Pattern**: Pin runtime SDKs with exact versions (no `^` or `~`). `bun --filter @archon/providers add` failed with "No packages matched the filter"; `bun add --exact` from `packages/providers` updates both `package.json` and the root `bun.lock`.
- **Example**: `"@agentclientprotocol/sdk": "1.4.0"`, `"@deepseek-ai/dsh": "0.1.2-rc.1"`

### Community provider tests
- **Where**: `packages/providers/src/community/<name>/`
- **Pattern**: Tests use `bun:test`. ESLint ignores `**/*.test.ts`. Always run `bun test <file>` from `packages/providers`; never `bun test` from the repo root.
- **Example**: `bun test src/community/deepseek/ndjson-stream.test.ts`

### ACP SDK value-import isolation
- **Where**: `packages/providers/src/community/deepseek/ndjson-stream.test.ts`
- **Pattern**: Dynamic-import `@agentclientprotocol/sdk` in tests. Production code must keep ACP SDK *value* imports isolated to `acp-client.ts` (type-only elsewhere).
- **Example**: `const { ndJsonStream } = await import('@agentclientprotocol/sdk');`
