## Codebase Patterns

### Stateful ACP SessionUpdate translation (no fabricated usage)
- **Where**: `packages/providers/src/community/deepseek/event-bridge.ts`
- **Pattern**: `mapDeepseekSessionUpdate` uses an exhaustive `switch (update.sessionUpdate)` with a `never` default. Tool start stores `{ name, input }` by `toolCallId`; in-progress updates mutate that entry; `completed`/`failed` emit `tool_result` then `delete`. `usage_update` (even with `cost`) and other housekeeping variants emit `[]` — never `tokens`/`usageBreakdown`/`cost`. Non-text message/thought content is ignored, not stringified.
- **Example**: `mapDeepseekSessionUpdate(update, createDeepseekEventState())`

### Isolated child-env records (never mutate process.env)
- **Where**: `packages/providers/src/community/deepseek/env.ts`
- **Pattern**: `buildDeepseekChildEnv` takes `ambient`/`request` records. Tests pass isolated objects; never mutate `process.env`. Request overlays ambient, then config `baseUrl`, then `DSH_PERMISSION_MODE`. Empty/missing `DEEPSEEK_API_KEY` throws `deepseek_missing_api_key` without trimming or logging the value. Never writes `DSH_PROVIDER_ROUTE`.
- **Example**: `buildDeepseekChildEnv({ ambient, request, baseUrl, permissionMode })`

### Injectable DeepSeek runtime facts
- **Where**: `packages/providers/src/community/deepseek/node-resolver.ts` `DeepseekRuntimeFacts`
- **Pattern**: Inject `isBinary`/`execPath`/`isNodeHost`/`platform`/`findNodeOnPath` so tests cover POSIX vs Windows without changing `process.platform` or spawning a shell. POSIX uses `X_OK`; Windows only requires a regular file. Binary mode throws `deepseek_runtime_unavailable` before `createRequire()`.
- **Example**: `resolveDeepseekNodeBinary(configNodeBin, env, facts)`

### Typed DeepSeek errors + redaction
- **Where**: `packages/providers/src/community/deepseek/errors.ts`
- **Pattern**: `DeepseekProviderError(subtype, message)`. `toDeepseekErrorResult` keeps known subtypes, maps unknown to `deepseek_acp_error`, replaces every secret occurrence with `[REDACTED]`, and never synthesizes tokens/usage/cost/sessionId.
- **Example**: `toDeepseekErrorResult(error, [apiKey])` → `{ type: 'result', isError: true, errorSubtype, errors: [sanitized] }`

### DeepSeek config parser fail-fast + applied defaults
- **Where**: `packages/providers/src/community/deepseek/config.ts`
- **Pattern**: `parseDeepseekConfig` always returns `profile`/`providerRoute`/`permissionMode` defaults. Explicit `providerRoute` without `model` is rejected; the default route is allowed without a model. `maxTokens !== undefined` throws `DeepseekProviderError('deepseek_unsupported_config', ...)` with the pinned-ACP message.
- **Example**: `'assistants.deepseek.maxTokens is unsupported: pinned DSH ACP exposes only model and reasoning_effort.'`

### DeepSeek effort switch (not clampEffort)
- **Where**: `packages/providers/src/community/deepseek/config.ts` `resolveDeepseekEffort`
- **Pattern**: Use an explicit `switch`, not `clampEffort`. Map `minimal->off`, `medium->low`, `xhigh->high`; preserve `off`/`low`/`high`/`max`; throw on blank/unknown. `off` is not on `EFFORT_LADDER`.
- **Example**: `resolveDeepseekEffort('minimal') === 'off'`

### Exact provider dependency pins
- **Where**: `packages/providers/package.json`
- **Pattern**: Pin runtime SDKs with exact versions (no `^` or `~`). `bun --filter @archon/providers add` failed with "No packages matched the filter"; `bun add --exact` from `packages/providers` updates both `package.json` and the root `bun.lock`.
- **Example**: `"@agentclientprotocol/sdk": "1.4.0"`, `"@deepseek-ai/dsh": "0.1.2-rc.1"`

### Community provider tests
- **Where**: `packages/providers/src/community/<name>/`
- **Pattern**: Tests use `bun:test`. ESLint ignores `**/*.test.ts`. Always run `bun test <file>` from `packages/providers`; never `bun test` from the repo root.
- **Example**: `bun test src/community/deepseek/ndjson-stream.test.ts`

### ACP SDK value-import isolation
- **Where**: `packages/providers/src/community/deepseek/ndjson-stream.test.ts`
- **Pattern**: Dynamic-import `@agentclientprotocol/sdk` in tests. Production code must keep ACP SDK *value* imports isolated to `acp-client.ts` (type-only elsewhere).
- **Example**: `const { ndJsonStream } = await import('@agentclientprotocol/sdk');`
