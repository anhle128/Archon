## Codebase Patterns

### Operator docs insertion points
- **Where**: `packages/docs-web/src/content/docs/adapters/web.md`, `reference/api.md`, `reference/security.md`
- **Pattern**: Execution Detail Page lists Graph, Logs, optional Chat, Source Control, Terminal. WebSocket docs go after run actions and before `## Commands`, and must say the route is not in OpenAPI. Threat-model copy goes under `## Secrets Handling` before Target repo `.env` isolation. Keep full Markdown sentences on one physical line.
- **Example**: `#### Run Terminal WebSocket`

### Legacy DAG terminal tab body
- **Where**: `packages/web/src/components/workflows/source-control/dag-run-tabs.tsx`, `WorkflowExecution.tsx`, `terminal/terminal-tab.tsx`
- **Pattern**: `WorkflowRunView` includes `'terminal'`. Put `<TabsTrigger value="terminal">Terminal</TabsTrigger>` immediately after Source Control. `resolveWorkflowExecutionBody` returns `'terminal'` only for DAG + `activeView === 'terminal'`; every non-DAG view stays `'sequential'`. Render `<TerminalTab key={runId} runId={runId} />`. Overlay `TerminalStatus` when not connected; show connected copy in the toolbar. Static-render `TerminalTab` tests so `useEffect` never mounts xterm. Decode `&#x27;` when asserting copy that contains apostrophes.
- **Example**: `if (input.activeView === 'terminal') return 'terminal';`

### Injected browser terminal ports
- **Where**: `packages/web/src/components/workflows/terminal/client.ts`, `xterm-session.ts`
- **Pattern**: Inject location, sessionStorage, socket factory, clock, and timers into `createRunTerminalClient`. Inject Terminal/FitAddon/ResizeObserver/requestFrame/client factories into `mountXtermSession`. Never `mock.module()`. Mirror server control parsing locally — do not import `@archon/server`. Split input with `TextEncoder` on code points. `disconnect()` keeps the resume token; `closeSession()` sends `{ type: 'close' }` and clears it. Close code 4001 is a non-reconnecting error.
- **Example**: `url.protocol = location.protocol === 'https:' ? 'wss:' : 'ws:';`

### Injected terminal endpoint deps
- **Where**: `packages/server/src/routes/terminal/endpoint.ts` (`createTerminalEndpoint`)
- **Pattern**: Inject auth, run lookup, target resolution, spawn, and the session manager. Default deps import `getAuth`, `isApiGateEnabled`, `userDb.findOrCreateUserByPlatformIdentity`, `workflowDb.getWorkflowRun`, and `isolationEnvDb.getById`. Never `mock.module()`. Origin check runs before auth. `createFetchWithTerminal` intercepts `TERMINAL_PATH_RE` before Hono and preserves `undefined` on a successful upgrade.
- **Example**: `if (endpoint.matches(pathname)) return endpoint.handleUpgrade(request, server);`

### Injected session manager clock, tokens, and sockets
- **Where**: `packages/server/src/routes/terminal/session-manager.ts` (`createTerminalSessionManager`)
- **Pattern**: Inject `randomBytes`, `setTimeout`, `clearTimeout`, and a lifecycle logger. Tests use fake sockets (`send` result queue, `getBufferedAmount`) and fake PTYs. Key by `${userId}:${runId}`. Copy every PTY chunk. Compare resume tokens with `timingSafeEqual` after `isResumeToken`. Centralize removal in `destroy(key, reason)`: delete map entry, cancel timer, kill PTY, close socket. Socket identity checks so replaced sockets cannot mutate the current session.
- **Example**: `if (session?.socket !== socket) return undefined;`



### Injected Bun.spawn for PTY tests
- **Where**: `packages/server/src/routes/terminal/pty.ts` (`spawnTerminalPty`)
- **Pattern**: Inject `spawn?: typeof Bun.spawn`. Unit tests pass a fake subprocess; only the POSIX Ctrl-C case uses production `Bun.spawn`. Use inline `terminal: { cols, rows, name: 'xterm-256color', data }` — never `new Bun.Terminal()`. Fail fast if `subprocess.terminal` is absent. `kill()` is idempotent: `SIGTERM` then `terminal.close()`. Container specs omit `cwd` because `docker exec -w` already sets it.
- **Example**: `const spawn = input.spawn ?? Bun.spawn;`

### Fresh protocol result objects
- **Where**: `packages/server/src/routes/terminal/protocol.ts` (`parseClientControlMessage`)
- **Pattern**: Parse JSON in try/catch, switch only on `type`, validate locked fields, and return a new object so extra keys (`cwd`, `containerId`) never survive. Measure input with `Buffer.byteLength(..., 'utf8')`, not JS string length. Resize requires `Number.isInteger` plus the locked min/max.
- **Example**: `return { type: 'input', data: record.data };`

### Injected DockerRunner
- **Where**: `packages/server/src/routes/terminal/docker.ts`
- **Pattern**: Default `runDocker` wraps `execFileAsync` with a 5s timeout. Tests pass a `DockerRunner` so inspect/exec never hits a real daemon. Classify only case-insensitive `no such object|container` as missing; unexpected inspect stdout and daemon errors throw.
- **Example**: `if (/no such (object|container)/i.test(dockerErrorText(error))) return 'missing';`

### Isolation env before host filesystem
- **Where**: `packages/server/src/routes/terminal/target.ts` (`resolveTerminalTarget`)
- **Pattern**: Require `working_path` first, then load `metadata.isolation_env_id`. Provider `container` prefers `containerName` over `containerId`. `worktree` falls through to host `canonicalDirectory`. `vm`/`remote`/unknown return `unsupported_provider`. `metadata.isolation === 'container'` without a usable env never probes the host.
- **Example**: `nonEmptyString(environment.metadata.containerName) ?? nonEmptyString(environment.metadata.containerId)`

### Explicit env allowlist copy
- **Where**: `packages/server/src/routes/terminal/env.ts`
- **Pattern**: `copyAllowed` copies only non-empty strings from a const key list, then overwrites `TERM`/`COLORTERM`. Host vs Docker differ only by extra Docker connectivity keys. Never inherit `process.env` wholesale; `SSH_AUTH_SOCK` is excluded on purpose.
- **Example**: `if (typeof value === 'string' && value.length > 0) result[key] = value;`

### TerminalOriginError as HTTP boundary
- **Where**: `packages/server/src/routes/terminal/origin.ts`
- **Pattern**: Domain errors are `Error` subclasses with a numeric `status` and a locked `message`. Origin checks throw `TerminalOriginError` (`403`, `'Forbidden origin'`) instead of returning a boolean.
- **Example**: `throw new TerminalOriginError()`

### WEB_UI_ORIGIN same-host fallback
- **Where**: `packages/server/src/routes/terminal/origin.ts` (`assertTerminalOrigin`)
- **Pattern**: Concrete `WEB_UI_ORIGIN` (not `*`) compares normalized `URL.origin`. Unset or `*` compares origin hostname to `Host` hostname so Vite (`:5173`) can talk to the server (`:3090`).
- **Example**: `hostName(request.headers.get('Host') ?? '') !== origin.hostname`

### ESLint optional-chain vs null guard
- **Where**: `packages/server/src/routes/terminal/origin.ts`
- **Pattern**: `@typescript-eslint/prefer-optional-chain` rejects `!allowed || allowed.origin !== origin.origin`. Use `allowed?.origin !== origin.origin`.
- **Example**: `if (allowed?.origin !== origin.origin) throw new TerminalOriginError();`
