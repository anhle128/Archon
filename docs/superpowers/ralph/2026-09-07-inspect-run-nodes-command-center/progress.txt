## Codebase Patterns

### Chat and dock deep-link through consoleRunHref
- **Where**: `packages/web/src/experiments/console/components/console-run-href.ts`, `ConsoleWorkflowResultCard.tsx`, `WorkflowDock.tsx`
- **Pattern**: Path ids use `encodeURIComponent`; the node query uses `URLSearchParams({ node })`. Null node omits the query. Running dock cards pass `run.currentNode ?? null`; paused cards pass `run.approval?.nodeId ?? run.currentNode ?? null`. Isolation tests compact whitespace so prettier wrapping still proves the call.
- **Example**: `consoleRunHref(run.projectId, run.id, run.currentNode ?? null)` → `/console/p/proj%2Fa/r/run%201?node=review`

### Run detail splits log filter from inspect URL selection
- **Where**: `packages/web/src/experiments/console/routes/RunDetailPage.tsx`
- **Pattern**: `streamNodeFilter` keeps storage key `archon.console.runNodeFilter` and default `all`. `InspectSelection` is initialized once per run id via `resolveInitialInspectSelection`. Later `?node=` applies only when the param *value* changes; deleting it must not reopen a closed room. Preserve unrelated search params through `URLSearchParams` + `navigate({ search }, { replace: true })`.
- **Example**: `prevSearchNodeRef` records the last seen `node` query so closing the room cannot race a stale `?node=` back into selection.

### Unmerged log rows are selectable siblings of usage expansion
- **Where**: `packages/web/src/experiments/console/components/NodeDivider.tsx`, `RunStream.tsx`
- **Pattern**: Identity/status is one full-width button (`aria-current` when selected) calling `onSelect(rowId, nodeId)`. Usage expansion is a sibling chevron with an explicit `aria-label` so no control is nested. `RunStream` keeps `selectedNodeId` as the All-nodes filter and `foldNodeRuns` message windows; when `logEntries` is supplied it replaces folded one-divider-per-node rows. Ledger usage is passed only when `entry.showNodeUsage` is true. Omit `logEntries` to keep the legacy folded dividers until the inspect pane wires the projector.
- **Example**: `onSelectLogRow(entry.row.id, entry.row.nodeId)` with `hasLedgerUsage` only on the last chronological row per node

### Console graph panel is a pure renderer over shared layout
- **Where**: `packages/web/src/experiments/console/components/RunGraphPanel.tsx`
- **Pattern**: Memoize `buildRunGraphInput(nodes, nodeStates)`. SVG routes and HTML cards share `translate(64px, 64px) scale(s)` with 180×80 cards. Dashed = `backEdge || kind === 'conditional'`; untaken stroke is `var(--border)`. Manual zoom clamps to `[0.25, 1.5]` in 0.1 steps; Fit uses `fitGraphScale` (max 1.0) and centers after rAF. Happy DOM tests stub `clientWidth`/`clientHeight` and use `instanceof` guards instead of `as` casts. `RunGraphPanel` must not fetch, fold events, or import Dagre; the page/pane supplies `nodes` and `nodeStates`.
- **Example**: `onSelectNode(nodeId)` only — the panel never changes Log/Graph view.

### Console DAG layout uses public run-graph layout plus inspect-status
- **Where**: `packages/web/src/experiments/console/components/graph/build-run-graph-input.ts`, `graph-viewport.ts`
- **Pattern**: Import only `layout` and types from `@/lib/run-graph` (constants are not public). Keep a console-local `['positive', 'negative', 'exhausted'] as const`. Projected `nodeStates` are the only live status; last duplicate id wins; `inspectStatus` maps `awaiting` to `running` before layout. Route edges emit exhausted→negative→positive; colliding targets append `:${outcome}`. `graphBounds` uses 180×80 plus 64px padding; `fitGraphScale` defaults 24px padding and clamps to `[0.25, 1]`.
- **Example**: `layout({ nodes: graphNodes.map(n => ({ id: n.definition.id, nodeState: n.nodeState })), edges })`

### Console node rooms poll via useEntity, not React Query
- **Where**: `packages/web/src/experiments/console/components/ConsoleNodeRoom.tsx`, `packages/web/src/experiments/console/test/install-happy-dom.ts`
- **Pattern**: Key `useEntity` with `K.nodeMessages(run.id, nodeId)` only for agent rooms; every other kind uses a stable idle key plus `Promise.resolve({ messages: [] })` so `loadMessages` is never called. Hold fetches while `definitionPending` and resolution is the unknown-agent fallback. Poll with `globalThis.setInterval(..., 1000)` only when `isLive` and kind is `agent`; keep `refetch` in a ref so cache notifies do not reset the timer. Tests call `installHappyDom()` / `restoreHappyDom()`, inject `loadMessages`, spy `setInterval` without wall-clock, then `invalidate('run-node-messages')` after unmount because the cache retains subscriber-less values.
- **Example**: `useEntity(agentActive ? K.nodeMessages(run.id, nodeId) : 'console-node-room:idle', () => agentActive ? loadMessages(run.id, nodeId) : Promise.resolve({ messages: [] }))`


### Room dispatch is definition schema keys, then approval, then events
- **Where**: `packages/web/src/experiments/console/components/inspect/resolve-room-kind.ts`, `select-room-data.ts`, `select-node-room-messages.ts`, `console-inspect-selection.ts`
- **Pattern**: Mirror legacy `resolve-room-kind.ts` / `select-room-data.ts` / `NodeRoom.selectNodeRoomMessages`. Import `DagNode` from console workflows, `WorkflowEvent` / `WorkflowNodeState` / `WorkflowNodeMessage` from console runs, and `RunStatus` from `lib/run-status`. Definition data outranks metadata. Agent + `nodeType: 'unknown'` is last. Loop transcripts slice from `iteration_started` through matching terminal or next start; missing markers return the full seq-sorted copy. Valid `?node=` wins with `logRowId: null`; graph selection also clears the row id.
- **Example**: `resolveRoomKind(nodeId, dagNodes, events, approval)` then `selectNodeRoomMessages(messages, row.selection)` and `resolveInitialInspectSelection({ requestedNodeId: readNodeSearchParam(search), nodeStates, rows, approvalNodeId })`

### Unmerged log projection pipeline is synthesize → rows → entries
- **Where**: `packages/web/src/experiments/console/components/inspect/build-log-rows.ts`, `synthesize-log-node-states.ts`, `build-console-log-entries.ts`
- **Pattern**: Mirror the legacy `packages/web/src/components/workflows/build-log-rows.ts` contract, but import `WorkflowEvent` / `WorkflowNodeState` from console skills (type-only generated types). Existing projected states always win; synthetics come only from loop-iteration events, `approval_requested` with `gateType` `approval`|`plannotator_gate`, or a paused selectable approval (`approval` / `plannotator_gate` / `child_workflow` / omitted type). Ordinary `node_started`/terminal events never synthesize. Loop terminal duration is `data.duration_ms` then `data.duration`, finite and ≥ 0. `showNodeUsage` is true only on the last chronological row per `nodeId`.
- **Example**: `buildLogRows(synthesizeLogNodeStates(nodeStates, events, status, approval), events)` then `buildConsoleLogEntries({ rows, rawEvents: events, nodeRuns: foldNodeRuns(events.map(toRunEvent)), runStartedAt })`

### Console inspect policy is owned under components/inspect, not @/lib
- **Where**: `packages/web/src/experiments/console/components/inspect/read-approval-context.ts`, `inspect-status.ts`
- **Pattern**: NFR4 forbids runtime `@/lib/approval-context`. Console copies the parser contract as `ApprovalContext` / `readApprovalContext` / `getPlannotatorReviewUrl`. Object guard is `isRecord` (object, non-null, non-array) so no `any` and arrays fail closed. Invalid `type` or `resolved` enum returns `null`; wrong-typed optional scalars are dropped.
- **Example**: `inspectStatusLabel` passes arbitrary transcript strings through; `inspectStatus` maps unknowns to `'pending'`; only `'running'` and `'paused'` are live.

### Console fetch contract tests use spyOn, not mock.module
- **Where**: `packages/web/src/experiments/console/skills/runs.node-messages.test.ts`, `packages/web/src/experiments/console/skills/workflows.dag-nodes.test.ts`
- **Pattern**: `spyOn(globalThis, 'fetch').mockImplementation((...) as typeof fetch)` with `afterEach` `mockRestore()`. `requestJson` JSON-parses the body, so assert unreshaped payloads with `toEqual`, not object identity `toBe`.
- **Example**: `expect(result.rawEvents).toEqual([rawEvent])`

### Collision-safe console cache keys encode each segment
- **Where**: `packages/web/src/experiments/console/store/keys.ts`
- **Pattern**: Join `encodeURIComponent` of each id/cwd/name so `:` or `/` in one segment cannot collide with another.
- **Example**: `` `run-node-messages:${encodeURIComponent(runId)}:${encodeURIComponent(nodeId)}` ``

### Workflow DAG reads go through GET /api/workflows list
- **Where**: `packages/web/src/experiments/console/skills/workflows.ts` (`getWorkflowGraph`, `getWorkflowDagNodes`)
- **Pattern**: List + exact `workflow.name` match, then throw `Workflow not found: ${name}`. Do not call `/api/workflows/:name` (it misses subfolder workflows).
- **Example**: `getWorkflowDagNodes('deploy/workflow', '/repo path')` → `/api/workflows?cwd=%2Frepo%20path`
