## Codebase Patterns

### Avoid bang-prefixed lines in eval Python strings
- **Where**: `packages/web/src/components/workflows/WorkflowExecution.tsx` roomFooter wiring
- **Pattern**: A line that begins with bang inside an eval-tool Python string is interpolated as a shell snippet and can rewrite source to `__omp_shell(...)`. Prefer `isRunning || length === 0` over a bang-prefixed condition. Keep unique-string Python with match count == 1 and `export function WorkflowExecution` as the surviving marker.
- **Example**: `isRunning || workflow.artifacts.length === 0 ? undefined : footer`

### HappyDOM QueryClient transcript tests
- **Where**: `packages/web/src/components/workflows/NodeTranscriptPane.test.tsx`
- **Pattern**: `NODE_ENV=production` loads React without `act`. Set `process.env.NODE_ENV = 'development'` then dynamically import react/react-query/react-dom and the pane. Do not destructure PascalCase names from `await import` (`naming-convention`). Make Query notifications sync with `notifyManager.setScheduler(cb => cb())` and restore afterEach. Restore HappyDOM globals, unmount the root, `win.close()`, and `queryClient.clear()` so `bun test src/components/` is not polluted. Never StrReplace this file — unique-string Python with a surviving later marker.
- **Example**: `const reactQuery = await import('@tanstack/react-query'); new reactQuery.QueryClient({ defaultOptions: { queries: { retry: false } } })`

### Static markup HTML entities
- **Where**: `packages/web/src/components/workflows/NodeRoom.test.tsx`
- **Pattern**: `renderToStaticMarkup` encodes apostrophes as `&#x27;` and quotes as `&quot;`. Decode in `visibleText` before asserting exact copy or JSON tool input.
- **Example**: `.replace(/&#x27;/g, "'").replace(/&quot;/g, '"')`

### NodeRunList static markup and status colors
- **Where**: `packages/web/src/components/workflows/NodeRunList.tsx`, `NodeRunList.test.tsx`
- **Pattern**: Copy StatusBadge classes from WorkflowExecution (`bg-success/20 text-success`, etc.). `onSelect` receives the full LogRow. Web `*.test.tsx` is ESLint-checked unlike `*.test.ts`; avoid `String#match` (`prefer-regexp-exec`) and void-expression onClick shorthands. Tests use `renderToStaticMarkup`.
- **Example**: `aria-current={selected ? 'true' : undefined}` and `onClick={(): void => { onSelect(row); }}`

### Unique-string rewrite for WorkflowExecution.tsx
- **Where**: `packages/web/src/components/workflows/WorkflowExecution.tsx`
- **Pattern**: Editor text-replace truncated this 885-line file to 255 lines. Restore with `git checkout --`, then unique-string Python with match count == 1, line-count assertion, and a surviving later marker such as `export function WorkflowExecution`. Keep `runtimeMetadataFromEventData` while `currentlyExecuting` still spreads it.
- **Example**: `assert 'export function WorkflowExecution' in text` after writing


### Isolated OpenAPI type generation
- **Where**: `packages/web/package.json` `generate:types`, `packages/web/src/lib/api.ts`
- **Pattern**: Do not reuse a listener on 3090 from another checkout. Start `startServer({ port, skipPlatformAdapters: true })` with a temp `ARCHON_HOME` and empty `DATABASE_URL`, then run `openapi-typescript` against that live `/api/openapi.json`. Never hand-edit `api.generated.d.ts`. Mirror `api.conversations.test.ts` fetch spies; success path does not need `window`.
- **Example**: `getWorkflowNodeMessages(runId, nodeId)` encodes both path ids and returns `WorkflowNodeMessagesResponse`

### Loop transcript recording
- **Where**: `packages/workflows/src/dag-executor.ts` `executeLoopNode`
- **Pattern**: Local `recordLoopStatus` keyed by prefixed `stepName`. Await started after scheduled `node_started`; failed inside `failLoopNode` after scheduled `node_failed`; iteration markers after the matching loop_iteration_* events with `detail: String(i)`; `iteration_failed` before `failLoopNode` at both existing failed-event sites. Cleaned non-empty assistant text and tool rows use the same id/input rule as command/prompt. Completed only after `node_completed` on completionDetected and after `finalizeLoopFromSignal`. Do not record loop-group container output.
- **Example**: `await recordLoopStatus('iteration_started', String(i))` after `loop_iteration_started`

### Command/prompt transcript recording
- **Where**: `packages/workflows/src/dag-executor.ts` `executeNodeInternal`
- **Pattern**: Await `appendNodeTranscript` after scheduling the matching lifecycle event. Record assistant text at the start of the non-empty assistant branch, before batch/stream send. Tool rows use the chosen toolCallId and omit `input` when undefined. Fail-open stays in `node-transcript.ts`. Move `$node.output.field` substitution into the prompt-substitution try and wrap `getAgentProvider` so both return a failed NodeExecutionResult instead of escaping to runLayers.
- **Example**: `await recordNodeStatus('started')` after `node_started`; `await recordFailedStatus(err.message)` after `node_failed`

### Mock store retains sequenced transcript rows
- **Where**: `packages/workflows/src/dag-executor.test.ts` `createMockStore`
- **Pattern**: Keep append inputs in an array, assign increasing seq, and filter `listNodeMessages(runId, nodeId)` by identity then sort by seq. Table-driven command/prompt tests live in a dedicated describe at the end of this 24k-line file.
- **Example**: `expect(transcriptTimeline(rows)).toEqual(['started', 'text', 'tool', 'text', 'completed'])`


### Isolated @archon/paths mock shard
- **Where**: `packages/workflows/src/node-transcript.test.ts`, `packages/workflows/package.json`
- **Pattern**: mock.module('@archon/paths') then dynamically import the helper so createLogger is intercepted. Keep `bun test src/node-transcript.test.ts` as its own invocation beside logger.test.ts. Do not mix it into the schema shard. ESLint ignores the test file; lint the production helper only.
- **Example**: `appendNodeTranscript` logs `{ workflowRunId, nodeId, kind, errorType }` under `workflow.node_message_append_failed` and never the payload

### Unique-string rewrite for store-adapter.test.ts
- **Where**: `packages/core/src/workflows/store-adapter.test.ts`
- **Pattern**: Editor text-replace can truncate this 1100+ line file even when the replace reports not-found. If `wc -l` drops, restore with `git checkout --`. Apply unique-string replacements in Python with match count == 1, an expected line delta, and a surviving later marker such as `createWorkflowDeps`.
- **Example**: `assert text.count(old) == 1` then `assert 'createWorkflowDeps' in text` after writing

### Additive schema: table then trailing comments
- **Where**: `migrations/000_combined.sql`, `packages/core/src/db/adapters/sqlite.ts`
- **Pattern**: New tables go in CREATE TABLE after the last application table and before `-- Indexes and column comments`. COMMENT ON TABLE may sit beside CREATE. COMMENT ON COLUMN and CREATE INDEX go only in the trailing section. Do not add a new table to migrateColumns; CREATE TABLE IF NOT EXISTS creates it on existing DBs. After the migration, run `bun run generate:bundled-schema`. Raise MIN_NON_AUTH_COLUMNS by the new column count.
- **Example**: table 22 `remote_agent_workflow_node_messages` — unique `(workflow_run_id, node_id, seq)` is the covering lookup/order index, so no extra CREATE INDEX.

### Narrow IWorkflowStore capabilities
- **Where**: `packages/workflows/src/store.ts`
- **Pattern**: Add a dedicated interface (IRunTreeStore, IWorkflowEnvOverlayStore, IWorkflowNodeMessageStore) and compose it onto IWorkflowStore with `extends`. Do not add the new methods as loose members of the fat interface.
- **Example**: `export interface IWorkflowStore extends IRunTreeStore, IWorkflowEnvOverlayStore, IWorkflowNodeMessageStore`

### Workflow package type-check excludes tests
- **Where**: `packages/workflows/tsconfig.json`
- **Pattern**: `exclude: ["**/*.test.ts"]`, so `bun x tsc --noEmit` will not catch missing IWorkflowStore methods on test doubles. Still update every named typed double. The real core adapter is a later story.

### Schema test shard
- **Where**: `packages/workflows/package.json` `test` script
- **Pattern**: Schema tests belong in the existing mock-safe invocation with `src/schemas.test.ts` and `src/schemas/env-overlay.test.ts`. Do not add a new bun test process for schema files. Keep mock.module suites in their own invocations.

### Zod conventions
- **Where**: `packages/workflows/src/schemas/*.ts`
- **Pattern**: Import `z` from `@hono/zod-openapi`, derive types with `z.infer`, use `.strict()` objects, and `z.record(z.string(), valueSchema)`. Discriminated unions keep kind/payload correlated.

### Large-file edits
- **Where**: `packages/workflows/src/subrun.test.ts`, `dag-executor.test.ts`, `packages/core/src/workflows/store-adapter.ts`, `store-adapter.test.ts`
- **Pattern**: Line-anchored text replace can truncate these files. Prefer a unique-string in-place rewrite that asserts match count == 1 and verifies line count after writing.

### Core IWorkflowStore adapter is in the type-check graph
- **Where**: `packages/core/src/workflows/store-adapter.ts`
- **Pattern**: Core `tsc` includes store-adapter. Adding methods to IWorkflowStore fails `bun x tsc --noEmit` until createWorkflowStore wires them. Mock `../db/workflow-node-messages` in store-adapter.test.ts before the dynamic import; that file shares a bun test invocation with child-isolation-resolver.test.ts.
- **Example**: `appendNodeMessage: input => workflowNodeMessageDb.appendNodeMessage(input)`

### Dialect numeric coercion
- **Where**: `packages/core/src/db/workflow-node-messages.ts`
- **Pattern**: `@typescript-eslint/no-unnecessary-type-conversion` rejects `Number()` on a `number`. Type PG/SQLite MAX() results as `number | string` when both dialects can appear.
- **Example**: `query<{ next_seq: number | string }>(...)` then `Number(next.rows[0]?.next_seq ?? 1)`
