## Codebase Patterns

### Final isolation guard asserts console-owned Ask imports
- **Where**: `packages/web/src/experiments/console/console-isolation.test.ts`
- **Pattern**: Keep the NFR4 import scan. Replace premature HITL identifier bans with `Ask UI stays console-owned and out of the conversation composer`: compact() import specs (`from'./ask/ConsoleAskCard'`, `from'../components/ask/ConsoleAskChrome'`), ban `components/workflows` and `/ChatComposer` on room/pane/page, and scan ChatComposer/ChatPage for HITL identifiers.
- **Example**: `expect(room).toContain("from'./ask/ConsoleAskCard'")`

### RunDetailPage owns Ask mutation with runId-keyed state
- **Where**: `packages/web/src/experiments/console/routes/RunDetailPage.tsx`, `components/ConsoleInspectPane.tsx`
- **Pattern**: Keep `askActions` as `{ runId, states }` and ignore stale states when the route id changes. Invalidate `K.run(runId)` plus `K.nodeMessages(runId, selectedNodeId)` via a ref. Gate `a`/`r` with `hasDeclaredGate = isPaused && detail?.run.approval != null`. ConsoleInspectPane Ask props are required (`pendingInteractions`, `viewerIsStarter`, `starterDisplayName`, `actionStates`, `onSubmitAsk`). Header copy is `isPaused && askAwaiting ? 'Awaiting input' : statusLabel[run.status]`.
- **Example**: `when: (): boolean => hasDeclaredGate`

### ConsoleNodeRoom Ask placement uses generic transcript slots
- **Where**: `packages/web/src/experiments/console/components/ConsoleNodeRoom.tsx`, `ConsoleInspectPane.tsx`
- **Pattern**: AgentTranscript stays HITL-free with `renderAfterMessage` / `renderAtEnd`. Compute visibleAsks only when `resolution.kind === 'agent'`; split anchored vs unanchored by visible tool ids; on transcript error treat allMessages as `[]` so pending Asks stay unanchored after Retry. Pane Ask props are optional this task (`[]` / `false` / `null` / `{}` / async no-op) and pass through unchanged. Room tests need `[...FIXTURE]` because `WorkflowNodeMessagesResponse.messages` is mutable.
- **Example**: `renderAtEnd={unanchoredAsks.length === 0 ? undefined : unanchoredAsks.map(renderAskCard)}`

### ConsoleAskChrome is a Story 6.5 copy with layout classes and Run status
- **Where**: `packages/web/src/experiments/console/components/ask/ConsoleAskChrome.tsx`
- **Pattern**: Copy `WorkflowAskChrome`. Swap types to `Run['status']` and `WorkflowNodeState` from `../../skills/runs`. Rename the export/props. Keep error-first CAP-7 banner, awaiting pill, callback order (`onRequestGraphView` then `onSelectAwaitingNode`), and warning/error classes. Prepend `mx-6 mt-3 w-fit` on both roots so the chrome sits under `RunDetailHeader` without a wrapper on null. Hookless tests can call the component as a function and use `renderToStaticMarkup`; add the declared-gate `null` cases the Story 6.5 suite omitted.
- **Example**: `className="mx-6 mt-3 w-fit rounded-full border border-warning bg-warning/10 ..."`

### Console Ask card tests use happy-dom createRoot, not renderToStaticMarkup
- **Where**: `packages/web/src/experiments/console/components/ask/ConsoleAskCard.test.tsx`, `packages/web/src/experiments/console/test/install-happy-dom.ts`
- **Pattern**: `NODE_ENV=development` + React 19 development JSX makes `renderToStaticMarkup` throw `dispatcher.getOwner is not a function`. Use `installHappyDom`/`restoreHappyDom` and `createRoot`, then assert `host.innerHTML` / `textContent`. Alias PascalCase component imports to camelCase (`askCard`) for `@typescript-eslint/naming-convention`. Native decline uses `<dialog role="dialog" aria-modal="true">` and `showModal()`/`close()`; assert `dialog.open`.
- **Example**: `harness.root.render(createElement(askCard, cardProps(overrides)))`

### Awaiting warning chrome uses `--warning` tokens, not `--running`
- **Where**: `packages/web/src/experiments/console/components/NodeDivider.tsx`, `RunGraphPanel.tsx`
- **Pattern**: Divider `STATUS_COLOR.awaiting` is `text-warning`. Graph `InspectCardStatus` includes `'awaiting'` with warning `color-mix` fill/border, `statusGlyphClass` `text-warning`, and `animate-[pulse_2.4s_ease-in-out_infinite] motion-reduce:animate-none` (running stays `animate-pulse`). Labels still go through `inspectStatusLabel`. Keep existing `routeLoopStates()` fixtures independent; set `review` to `awaiting` only in the warning-chrome test.
- **Example**: `status === 'awaiting' ? 'animate-[pulse_2.4s_ease-in-out_infinite] motion-reduce:animate-none' : ''`

### Expanding InspectStatus to awaiting requires NodeDivider to consume InspectStatus
- **Where**: `packages/web/src/experiments/console/components/NodeDivider.tsx`, `RunStream.tsx:457`
- **Pattern**: `buildConsoleLogEntries` types `displayStatus` as `InspectStatus`. `RunStream` passes that into `NodeDivider` without mapping. Adding `'awaiting'` to `InspectStatus` is a type error until `NodeDividerProps.status` is `InspectStatus` and `STATUS_COLOR` has an `awaiting` key. Labels go through `inspectStatusLabel`, not a local identity map. Warning tokens are `text-warning` / `--warning` in NodeDivider and RunGraphPanel (US-007).
- **Example**: `status: InspectStatus` and `{inspectStatusLabel(status)}`

### Console Ask presentation swaps WorkflowNodeStateResponse for WorkflowNodeState
- **Where**: `packages/web/src/experiments/console/components/ask/ask-card-presentation.ts`
- **Pattern**: Copy Story 6.5 `resolveAskCardPresentation`. Import types from `../../skills/runs` and `AskActionState` from `./ask-answer-controller`. Replace every `WorkflowNodeStateResponse` with `WorkflowNodeState`. Tests copy the Story 6.5 view-state table unchanged besides the skills/runs import.
- **Example**: `import type { AskAnswerBody, PendingInteraction, WorkflowNodeState } from '../../skills/runs';`

### Console Ask controller uses HttpError for 409, not getApiErrorStatus
- **Where**: `packages/web/src/experiments/console/components/ask/ask-answer-controller.ts`
- **Pattern**: Copy Story 6.5 `createAskAnswerController`. Swap API types to `../../skills/runs` and import `HttpError` from `../../lib/http`. Replace `getApiErrorStatus(error) === 409` with `error instanceof HttpError && error.status === 409`. Tests copy the Story 6.5 suite except the 409 fixture is `new HttpError(409, '/ask', 'taken')`.

### Console Ask selector copies Story 6.5 helpers without merge types
- **Where**: `packages/web/src/experiments/console/components/ask/select-visible-node-ask-interactions.ts`
- **Pattern**: Copy `collectToolIds`, `sortedBySeq`, `visibleReachesTranscriptTail`, and `selectVisibleNodeAskInteractions` from `packages/web/src/components/workflows/merge-agent-room-items.ts`. - **Where**: `packages/web/src/experiments/console/components/ask/parse-ask-envelope.ts`
- **Pattern**: Duplicate legacy `packages/web/src/components/workflows/parse-ask-envelope.ts` byte-for-byte. The only source change is `import type { AskAnswerBody } from '../../skills/runs'` instead of `@/lib/api`. Tests copy the Story 6.5 behavioral table unchanged. ### Console run skills re-export generated OpenAPI types
- **Where**: `packages/web/src/experiments/console/skills/runs.ts`
- **Pattern**: Console code never imports `@/lib/api` functions. Re-export schema types from `@/lib/api.generated` (`components['schemas'][...]`) and call APIs through console `requestJson`. ### GET-run Ask mapping treats non-string metadata.error as null
- **Where**: `packages/web/src/experiments/console/skills/runs.ts` `getRun`
- **Pattern**: `runError` is `typeof metadataError === 'string' ? metadataError : null`. `viewerIsStarter` uses `=== true` so a missing runtime field is false; keep that comparison even though OpenAPI types it as boolean, with the eslint-disable for `no-unnecessary-boolean-literal-compare`.
- **Example**: `{ unsafe: true }` metadata error → `runError: null`.
