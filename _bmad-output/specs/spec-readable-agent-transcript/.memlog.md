- (decision) User chose: normalize per-provider shapes at the edge rather than branching in the renderer. ToolPresentation stays render-neutral; each provider gets a small normalizer in lib/. - (decision) todo normalizes to TodoPhase[]: OMP folds nine ops; Claude's whole-list TodoWrite is a degenerate fold (last call wins) into a single Tasks phase, three statuses widened to five.
- (decision) task normalizes to TaskSubtask[]: OMP's batch yields one entry per tasks[] element; Claude's single Agent dispatch yields exactly one, description as name, subagent_type as agent. Claude has no batch-level context, so the context block is empty for Claude.
